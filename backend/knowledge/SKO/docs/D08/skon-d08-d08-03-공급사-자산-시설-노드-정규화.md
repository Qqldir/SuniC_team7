#### 4.1 국가 태그와 실제 원산지

| 사례 | 공개 가능한 태그 | 금지되는 해석 |
|---|---|---|
| SQM LiOH | `mine/brine_country=CL`, `conversion_country=CL`의 구조 경로 | 모든 SK온 입고 lot가 Salar de Atacama산이라고 확정 |
| PPLS LiOH | `resource_country=AU`, `refining_country=KR`의 구조 경로 | 43,000t/년 전체가 SK온 물량이라고 계산 |
| EcoPro Innovation LiOH | `refining/production_country=KR` | 상류 광물도 한국산이라고 기록 |
| POSCO Argentina lithium | `resource_country=AR`, `project=Sal de Oro/Hombre Muerto` | 공식 계약에 없는 LiOH/Li2CO3 제품형태를 지정 |
| Glencore cobalt | `supplier_domicile=CH`, `historical_resource_country=CD` | 스위스를 광산국으로 기록하거나 종료계약을 현행화 |
| Indonesia MHP MOU | `planned_resource/refining_country=ID` | 발표 능력 30,000 contained Ni tpa를 가동능력·SK온 구매량으로 합산 |
