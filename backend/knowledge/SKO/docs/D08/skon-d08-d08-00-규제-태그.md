### 11. 규제 태그

| 태그 | 의미 |
|---|---|
| `US_PFE_ENTITY` | 미국 세법상 PFE 정의·소유/통제 검토 필요 |
| `US_PFE_MATERIAL_ASSISTANCE` | PFE로부터의 material assistance 및 MACR 검토 필요 |
| `US_LOCAL_CONTENT` | 미국 내 생산·조달 또는 세액공제 적격성 검토 |
| `EU_BATT_CF` | EU 배터리 탄소발자국 산정·선언 데이터 필요 |
| `EU_BATT_DD` | 코발트·천연흑연·리튬·니켈 등 배터리 실사 대상 검토 |
| `EU_RECYCLED_CONTENT` | 재활용 원료 함량 및 증빙 검토 |
| `OECD_CAHRAs` | 분쟁·고위험지역 위험기반 실사 |
| `RMI_EMRT` | 코발트·구리·천연흑연·리튬·니켈 공급망 보고 템플릿 연계 |

미국의 PFE는 2025년 7월 4일 제정된 법 개정으로 세법에 도입되었으며, 2026년 IRS Notice 2026-15는 PFE와 material assistance cost ratio(MACR)에 관한 잠정 세이프하버와 입증 원칙을 제시한다. EU 배터리 규정은 배터리의 탄소발자국, 원료의 윤리적 조달, 공급 안정성, 재활용을 하나의 수명주기 규제체계로 다룬다. 상세 적용일·임계값·예외는 D08-08과 D08-09에서 별도 버전 관리한다.

## D08-01 Battery Material Taxonomy

### 1. 분류 원칙

소재는 ‘원소명’만으로 관리하지 않고 **공급망 단계 + 배터리급 형태 + 기능 + 화학계 + 규제 속성**으로 구분한다. 예를 들어 리튬은 스포듀민 정광, 브라인, 탄산리튬, 수산화리튬, 재생 리튬염을 서로 다른 노드로 만든다. 니켈 역시 광석, MHP·매트, 황산니켈, NCM 전구체 내 니켈을 구분한다.

`sk_on_relevance`는 SK온의 실제 구매 여부가 아니라 기술·포트폴리오상 관련성을 표시한다. `sk_on_procurement_confirmed`가 별도로 `true`인 경우에만 확정 구매관계로 사용할 수 있다.
