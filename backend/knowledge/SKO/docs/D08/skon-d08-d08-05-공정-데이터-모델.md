### 2. 공정·데이터 모델

#### 2.1 액체 전해액

`Li salt → organic solvent → additive → formulation/blending → filtration/filling → tanker/drum → cell electrolyte injection`

- LiPF6·LiFSI, carbonate계 용매와 기능성 첨가제의 제조국·순도·불순물·수분은 완제품 공급사와 별도 sub-tier로 관리한다.
- 전해액은 조성과 첨가제 package가 셀 platform별로 달라질 수 있으므로 공급사 법인만으로 대체 가능성을 판단하지 않는다.
- Enchem의 2024 공시상 일반적인 원가구성(Li salt 약 45%, additive 약 30%, organic solvent 약 25%)은 공급사 측 설명이지 SK온의 특정 formula 또는 BOM이 아니다.

#### 2.2 분리막

`PE resin/base oil → film extrusion → biaxial wet stretching → extraction/drying → ceramic/polymer coating → slitting → cell stacking/winding`

- base film과 coating을 분리하고, 동일 공급사의 국가별 시설도 별도 노드로 둔다.
- SKIET의 전사 생산능력 14.8억㎡는 SK온 전용 물량이 아니다. 계약면적·실제 drawdown·도착공장은 공개자료만으로 계산하지 않는다.
- 중국 자회사 매각과 한국공장 생산중단 공시는 계약 존재와 별개의 공급연속성 이벤트로 연결한다.

#### 2.3 집전체

`copper/aluminum feedstock → rolling or electrodeposition → surface treatment → slitting → electrode coating`

- 알루미늄박은 양극 집전체, 동박은 음극 집전체로 연결하되 alloy·두께·폭·표면처리·인장강도별 승인 grade를 별도로 관리한다.
- 발표된 장기 예상물량과 확정 주문·실제 출하를 구분한다. 공급사 전사 고객 비중으로 SK온 구매액을 역산하지 않는다.
- 원료 금속의 광산·제련국과 재생원료 비율은 foil 생산국과 별개다.

#### 2.4 보조소재와 공정용 화학물질

| 소재 | 대표 기능 | 데이터상 주의점 |
|---|---|---|
| PVDF·수계 바인더 | 활물질·도전재 결착 | 화학계·전극별 grade와 PFAS 규제상태를 분리 |
| CNT·carbon black | 전자전도 경로 형성 | powder와 dispersion, carrier solvent, 함량을 분리 |
| NMP | 양극 slurry 용매 | 구매량과 회수·재생량을 분리; 최종 셀 잔류량으로 보지 않음 |
| 탭·리드 | 셀 외부 전기연결 | 금속조성·도금·실링필름·form factor별 승인 필요 |
| 고체전해질 | 전고체전지 이온전도 | R&D validation 물량과 상업생산용 공급을 분리 |

#### 2.5 최소 승인 키

`supplier legal entity + manufacturing facility + material/grade or formula revision + sub-tier origin + packaging/transport mode + SK On receiving plant + cell platform + approval revision + valid_from/to`

이 키가 빠진 고객목록·보도자료·투자관계는 후보 또는 부분확인 관계로만 둔다.
