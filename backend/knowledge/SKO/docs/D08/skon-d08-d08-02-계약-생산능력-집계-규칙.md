### 5. 계약·생산능력 집계 규칙

| 데이터 | 집계 가능 여부 | 이유/처리 |
|---|---|---|
| 엘앤에프 30만t 장기계약 | 계약 총량으로 별도 집계 | 실제 연도별 발주·출하와 구분하고 `announced_contract_quantity`로 저장 |
| 당성과기 1.7만t 예상 | 프레임워크 예상량으로 별도 집계 | 월별 PO가 실구매를 결정하므로 확정 구매량에 합산 금지 |
| 당성과기 추가 11만t | 확정량 집계 금지 | 비구속 잠재수요 |
| BTR 창저우 연 5만t | 시설 명목능력으로만 집계 | SK온 계약량이나 실제 출하량이 아님 |
| EcoPro CAM Canada 연 4.5만t | `suspended_nameplate`로만 보존 | 현재 가동능력·북미 공급량에 합산 금지 |
| 새만금 pCAM 연 5만t | 역사 계획치 | 취소 프로젝트이므로 현행 capacity에서 제외 |
| Eco&D pCAM 3만t 신규+5천t 기존 | 공급사 시설능력 | SK온 확정 물량으로 전환 금지 |
| 계약금액 | 명목 발표값으로만 보존 | 원재료 시세·환율·실제 발주량에 따라 변동; revenue·backlog·purchase commitment와 동일시 금지 |

계약 종료일은 검색 편의를 위해 발표상 종료일과 데이터베이스의 배타적 종료일을 함께 보존한다. 예를 들어 `announced_valid_through=2026-12-31`, `valid_to_exclusive=2027-01-01`로 저장한다.
