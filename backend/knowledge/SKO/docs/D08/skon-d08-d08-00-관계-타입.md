> SK온 · D08 원소재·공급사·공급망 · SK온 D08 — Raw Materials, Suppliers & Supply Chain > Domain Boundary

### 9. 관계 타입

| 관계 | 예시 의미 |
|---|---|
| `REQUIRES_MATERIAL` | 화학계·셀 제품이 특정 소재군을 필요로 함 |
| `SUPPLIES_TO` | 공급사가 SK온 또는 특정 공장에 공급 |
| `SIGNED_WITH` | 계약·MOU 당사자 관계 |
| `PRODUCED_AT` | 소재가 특정 시설에서 생산 |
| `EXTRACTED_FROM` | 정광·원료가 광산/염호에서 유래 |
| `REFINED_AT` | 중간재가 특정 정련시설에서 배터리급 물질로 전환 |
| `LOCATED_IN` | 자산·시설의 소재 국가·지역 |
| `OWNED_OR_CONTROLLED_BY` | 시설·법인의 지분·통제 관계 |
| `SUBJECT_TO_RULE` | 소재·시설·거래가 규제 적용 대상 |
| `HAS_RISK` | 엔터티가 공급망 위험에 노출 |
| `ALTERNATIVE_TO` | 소재·공급사·경로의 대체 관계 |
| `RECOVERED_AS` | 스크랩·폐배터리에서 회수 산출물로 전환 |
| `RETURNS_TO` | 재생원료가 배터리 소재·셀 공급망으로 복귀 |
