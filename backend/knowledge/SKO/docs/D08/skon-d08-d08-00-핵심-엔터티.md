> SK온 · D08 원소재·공급사·공급망 · SK온 D08 — Raw Materials, Suppliers & Supply Chain > Domain Boundary

### 6. 핵심 엔터티

| 엔터티 | 기본 키 | 최소 필드 |
|---|---|---|
| `Material` | `material_id` | 명칭, 화학식/등급, 소재군, 단계, 기능, 대체 가능성 |
| `MaterialGrade` | `grade_id` | 순도, 입도, 수분, 불순물, 고객승인 상태, 적용 화학계 |
| `Supplier` | `supplier_id` | 법인명, 본사국, 모회사, 소유구조, 공급 역할 |
| `Facility` | `facility_id` | 시설명, 국가·지역, 공정, 상태, 명목능력, PFE 관련 속성 |
| `MineOrBrine` | `origin_asset_id` | 자산명, 광종, 운영사, 국가, 프로젝트 단계 |
| `SupplyAgreement` | `agreement_id` | 당사자, 품목, 물량, 기간, 효력, 구속력, 공급지역, 근거 |
| `OriginPath` | `origin_path_id` | 채굴→정련→소재→셀공장의 단계별 시설·국가 |
| `RegulatoryRule` | `rule_id` | 관할, 조문/가이던스, 적용대상, 발효일, 증빙요건 |
| `SupplyRisk` | `risk_id` | 위험유형, 대상, 발생가능성, 영향, 신호, 완화수단 |
| `RecycledStream` | `stream_id` | 원료, 발생지, 처리사, 회수물, 회수율, 배터리급 복귀 여부 |
| `OISeed` | `oi_seed_id` | 문제, 근거, 제안, 가치축, KPI, 난이도, 데이터 요구 |
