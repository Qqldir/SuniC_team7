### 4. 규제·실사 우선 소재 플래그

| 우선순위 | 소재 | 이유 |
|---|---|---|
| P0 | 리튬, 니켈, 코발트, 천연흑연 | EU 배터리 실사와 미국 PFE/현지조달 판단의 중심이며 광산·정련 경로 추적이 필수 |
| P0 | pCAM, NCM/LFP CAM, 흑연 AAM | 중국 생산·기술·설비 집중도가 높은 병목 단계로 원재료만 추적해서는 위험을 포착할 수 없음 |
| P1 | 구리, 망간 | RMI 확장 보고 또는 배터리 핵심 공급망·탄소 관리상 중요 |
| P1 | 전해질염, 전해액, 분리막 | 공급차질 시 셀 생산을 즉시 멈출 수 있는 승인형 소재이며 현지화·PFE 판단 필요 |
| P1 | 동박·알루미늄박 | 대량 사용, 박막 품질, 에너지·탄소, 무역조치 영향이 큼 |
| P2 | 바인더·첨가제·도전재 | 사용량은 작아도 특정 배합·품질 승인으로 대체 리드타임이 길 수 있음 |
