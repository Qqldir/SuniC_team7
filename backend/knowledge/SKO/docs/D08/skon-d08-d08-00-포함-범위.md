> SK온 · D08 원소재·공급사·공급망 · SK온 D08 — Raw Materials, Suppliers & Supply Chain > Domain Boundary

### 3. 포함 범위

| 범주 | 포함 내용 |
|---|---|
| 원천 원료 | 리튬, 니켈, 코발트, 망간, 흑연, 실리콘, 철, 인, 구리, 알루미늄 및 배터리 핵심 화학원료 |
| 중간재 | 정광·브라인, MHP·매트, 배터리급 염·화합물, pCAM, CAM, AAM, 전해질염·용매·첨가제 |
| 셀 투입 부품 | 분리막, 동박, 알루미늄박, 바인더, 도전재, 탭·리드 소재 |
| 공급 관계 | 공급계약, 오프테이크, MOU, 전략적 제휴, JV, 투자, 장기구매, 테스트·인증 관계 |
| 원산지 | 광산/염호, 채굴국, 제련·정련시설, 소재공장, 공급사 법인·소유구조 |
| 규제 | 미국 PFE 및 현지조달/세액공제 관련 요건, EU 배터리 탄소발자국·실사·재활용 요건 |
| 리스크 | 국가·기업·광종 집중, 가격, 물류, 품질, 증설 지연, ESG, 제재·수출통제, 추적성 |
| 순환공급망 | 공정스크랩, 사용후 배터리, 블랙매스, 회수금속·회수염, 폐쇄루프 계약 |
| O/I | 원가·생산성·품질·안전·설비·자원·업무 효율 개선 시드 |

### 4. 제외·참조 범위

| 항목 | 처리 원칙 |
|---|---|
| SK온 공장 주소·라인·생산능력 | D07이 원본을 소유하며 D08은 `plant_id`만 참조한다. |
| 완성차 고객과 셀 공급계약 | 고객 도메인이 원본을 소유하며, 원료 수요 연결에 필요한 범위만 참조한다. |
| 셀 제조 세부 공정·설비 | 소재 투입점과 품질 영향까지만 D08에 기록한다. |
| 배터리 성능·특허·R&D 상세 | 소재 선택과 대체 가능성 판단에 필요한 수준만 기록한다. |
| 광물·소재의 전 세계 전체 시장 | SK온 노출, 대체소싱, 규제 또는 O/I 판단에 필요한 후보군만 포함한다. |
| 근거 없는 공급사 추정 | 지식그래프의 확정 관계로 만들지 않고 `HYPOTHESIS` 또는 후보 큐에만 보관한다. |
