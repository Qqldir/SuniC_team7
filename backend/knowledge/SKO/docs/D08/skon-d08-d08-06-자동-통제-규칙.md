### 5. 자동 통제 규칙

| control_id | 규칙 | 예외 발생 시 조치 |
|---|---|---|
| `CTL-AGR-01` | `EXPIRED/CANCELLED` 계약을 참조한 신규 PO 차단 | 구매·법무 승인 후 신규 agreement version 생성 |
| `CTL-PO-02` | PO 소재·grade·공급시설이 승인 AVL과 불일치하면 입고 보류 | 4M/PPAP·품질 승인 연결 |
| `CTL-ORG-03` | COO만 있고 광산·정련·소재시설 경로가 없으면 완전추적 금지 | 공급사 증빙 보완 요청 |
| `CTL-QTY-04` | 계약량, forecast, PO, 입고량의 단위를 표준화하지 않고 합산 금지 | kg/t/㎡/L 및 금속함량 기준 변환 |
| `CTL-PFE-05` | 중국계 또는 소유·통제 미확인 공급망은 미국향 투입 전 재검토 | D08-08 rule engine 호출 |
| `CTL-EU-06` | 탄소·재생원료·실사 데이터가 없는 EU향 lot을 결측으로 표기 | D08-09 evidence pack 보완 |
| `CTL-LOT-07` | supplier lot→receipt lot→cell batch 연결이 끊기면 추적성 점수 하향 | QMS/MES key 정합성 수정 |
