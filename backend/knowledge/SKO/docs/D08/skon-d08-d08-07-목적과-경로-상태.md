> SK온 · D08 원소재·공급사·공급망 · SK온 D08 — Raw Materials, Suppliers & Supply Chain > Origin, Refining, Logistics & Traceability

### 1. 목적과 경로 상태

원산지는 한 국가 필드가 아니라 `채굴/추출 → 중간재 → 정련 → 소재 → 셀`의 다단계 경로다. D08-02~05의 공개자료로 일부 단계가 확인된 대표 경로는 다음과 같으며, 모두 실제 SK온 lot까지 완전히 연결되지는 않는다.

| path_id | 공개 확인 범위 | 상태 | 핵심 단절점 |
|---|---|---|---|
| `PATH-SQM-SKON` | 칠레 brine·전환구조 → SQM LiOH 계약 | `PARTIAL_TRACE` | 계약 lot의 실제 자산·정련 batch·도착 CAM/셀 공장 |
| `PATH-PPLS-SKON` | 호주 Pilgangoora 후보원료 → 한국 광양 LiOH → SK온 계약 | `PARTIAL_TRACE` | 실제 SK온 lot 배정과 downstream CAM |
| `PATH-POSCO-ARG-SKON` | 아르헨티나 Sal de Oro → POSCO Argentina → SK온 계약 | `PRE_SHIPMENT_TRACE` | 4M 승인, 첫 출하, 화학형태, 셀 투입 |
| `PATH-ENCHEM-GA-SKBA` | sub-tier 미공개 → 미국 Georgia 전해액 → SK Battery America | `COMMERCIAL_PARTIAL` | Li salt·용매·첨가제 원산지와 lot |
| `PATH-SKIET-SKON` | 원료 미분해 → 다지역 LiBS → SK온 | `CONTRACT_PARTIAL` | 생산공장, PE·coating 원료, 면적, 도착공장 |
| `PATH-ARTIENCE-US/EU` | CNT·carrier 미공개 → 미국/헝가리 dispersion → SK온 | `COMMERCIAL_PARTIAL` | sub-tier 원료, 계약량, cell platform |
| `PATH-WUXING-SKON` | Al feedstock 미공개 → 중국 Al foil → 지정법인/공장 | `FRAMEWORK_PARTIAL` | 제련원·재생비율·실제 PO·입고 lot |

기준일 현재 공개자료로 `FULLY_TRACEABLE`인 SK온 소재 경로는 0개다. 이 수치는 공급망이 실제로 추적 불가능하다는 뜻이 아니라, 공개정보만으로 lot 단위 사슬을 입증할 수 없다는 뜻이다.

### 2. Chain-of-Custody 최소 증빙팩

| 단계 | 필수 증빙 |
|---|---|
| 광산·염호 | 자산명, 운영사, 국가·좌표, 채굴권, 광종, 생산기간, 실사·감사 |
| 중간재·정련 | 제련/정련시설, 투입 원료, 회수율, mass balance, smelter/refiner ID |
| 소재 | 제조법인·시설, grade, 배합/조성 revision, CoA, 생산일·lot |
| 무역·물류 | invoice, packing list, B/L·AWB, COO, HS code, Incoterms, 환적지 |
| 입고·생산 | PO, ASN, receipt lot, IQC, 창고이동, MES 투입 batch, scrap flow |
| 규제·ESG | ownership/control, EMRT, OECD risk assessment, 탄소·재생원료 증빙 |
