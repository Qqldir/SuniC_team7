### 2. 원소별 공정·추적성 모델

#### 2.1 추적성 상태

| traceability_status | 판정 기준 |
|---|---|
| `FULLY_TRACEABLE` | 실제 구매 lot가 광산/염호–중간재–정련–pCAM/CAM–SK온 입고 lot까지 연결되고 질량수지·CoO·감사 증빙이 존재 |
| `ASSET_LEVEL_PARTIAL` | 계약 상대방과 광산/염호·정련시설의 구조적 연결은 확인되지만 실제 계약 lot의 배정·질량수지가 미확인 |
| `REFINERY_COUNTRY_ONLY` | 정련·생산국만 확인되고 상류 광물 원산지 또는 특정 정련시설이 미확인 |
| `PROJECT_DESIGN_ONLY` | MOU/CFA가 광산·염호·시설을 지목하지만 FID·가동·출하가 미확인 |
| `HISTORICAL_PARTIAL` | 종료된 계약의 제품·원산지 일부만 확인 |
| `NO_PHYSICAL_FLOW` | 취소·종료·미발효 관계로 물리 공급을 만들지 않음 |
| `UNKNOWN` | 공개자료만으로 경로를 구성할 수 없음 |

현재 공개자료로 확인한 아래 관계 중 `FULLY_TRACEABLE`은 0개다. 특정 공급사의 일반 생산경로를 실제 SK온 계약 lot의 원산지로 자동 승계하지 않는다.
