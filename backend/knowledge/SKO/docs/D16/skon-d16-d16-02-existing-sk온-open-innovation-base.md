설비지능화 5개사 관계는 2023년 공개된 다자 기술협력으로, 제어기·센서·통신·전력·Robot·원격운영을 묶었다. D16에서는 이 생태계를 `이미 전사 도입됨`으로 표시하지 않고 **검증 가능한 기존 접점**으로만 사용한다. ([SK이노베이션](https://askinno.com/global/archives/16939))

### 2. 기존 협력축의 구조적 시사점

```text
Next-generation cell/process IP
  ├─ Solid Power: License + Pilot transfer
  └─ Factorial: Manufacturing-feasibility MOU

Product/business co-development
  └─ Standard Energy: VIB ESS

Factory digitalization
  ├─ Siemens DISW: Digital Twin MOU
  └─ Beckhoff / Cisco / ifm / Yaskawa / Woowon: Equipment intelligence validation

Circularity adjacency
  └─ SK ecoplant / TES / Ascend Elements: Affiliate-led recycling JV
```

현재 공개관계는 차세대 Cell과 설비 Layer에 상대적으로 집중돼 있다. D14·D15에서 요구한 DPP·PFE/MACR·품질 Genealogy·Field Signal·OT Cyber, D11~D13의 수익성·CAPEX·계약지능은 공개된 직접 파트너가 상대적으로 적어 D16의 신규 탐색 우선영역이 된다.
