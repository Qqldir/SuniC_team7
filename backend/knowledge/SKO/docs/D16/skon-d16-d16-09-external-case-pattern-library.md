## D16-09 External Case Pattern Library

| Case ID | 외부사례 | 확인된 Pattern | SK온에 복사하지 않을 것 | 재사용 가능한 설계 |
|---|---|---|---|---|
| `CASE-D16-01` | Panasonic Energy–Palantir | 분산된 공장 Data를 운영 Workflow와 연결 | 회사 발표 ROI를 SK온 ROI로 복사 | 1개 공장 Material–Process–Quality–Cost Ontology |
| `CASE-D16-02` | Siemens–FREYR/ACC | PLM·MES·Automation·Twin을 Scale-up에 연결 | MOU를 완성된 Gigafactory 성과로 해석 | Virtual Commissioning과 Ramp Gate |
| `CASE-D16-03` | Volvo EX90–Circulor | 개별 양산차에 Primary Supply-chain Data 기반 Passport | Volvo Supplier Network를 SK온이 즉시 사용 가능하다고 가정 | Model–Battery ID–Access Role–Lifecycle Update |
| `CASE-D16-04` | UBS AM–ACCURE | 여러 BESS Project에 독립 Battery Analytics 적용 | 730MW를 SK온 Cell 검증규모로 간주 | OEM/Cell maker와 분리된 ESS Safety Layer |
| `CASE-D16-05` | Hydrovolt–Claroty | 신규 Recycling Plant의 Asset·Remote Access Gap을 OT Context로 관리 | Battery Recycler 환경을 Cell Line과 동일시 | Commissioning 단계 Vendor Remote Access 제거 |
| `CASE-D16-06` | Mercedes-Benz–Icertis | 대규모 Supplier 계약을 중앙화하고 Enterprise System에 연결 | 83% 단축을 SK온 예상효과로 사용 | Clause–Owner–Obligation–ERP 연결 |
| `CASE-D16-07` | SK ecoplant/TES–Ascend | 전처리 거점과 후처리·재생소재 기술을 JV로 결합 | 계열사 지분을 SK온 물량·가격 권리로 간주 | Scrap–Black Mass–pCAM Qualification Closed Loop |
| `CASE-D16-08` | Toyota–Redwood | 회수·진단·재활용에서 재생 CAM/Anode Supply로 확장 | Toyota 계약조건·경제성을 SK온에 적용 | EOL·Scrap·재생소재 Offtake의 단계적 계약 |

외부사례의 가치는 `누가 유명한가`가 아니라 **문제·데이터·운영·계약·성과가 어떤 순서로 연결됐는가**에 있다.
