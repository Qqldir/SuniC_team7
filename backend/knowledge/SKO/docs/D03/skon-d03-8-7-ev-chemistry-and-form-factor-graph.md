# 8.7 EV Chemistry and Form-Factor Graph

```text
PROD-SKON-EV-001 High-Nickel Pouch Battery
├── USES_CHEMISTRY → CHEM-NCM
├── HAS_FORM_FACTOR → FORM-POUCH
├── HAS_VARIANT → PROD-SKON-EV-002 NCM9+
├── HAS_VARIANT → PROD-SKON-EV-003 SF Battery
└── SUPPORTS_APPLICATION → APP-SKON-001 Passenger BEV

PROD-SKON-EV-007 LFP EV Platform
├── USES_CHEMISTRY → CHEM-LFP
├── HAS_FORM_FACTOR → FORM-NOT-DISCLOSED
├── HAS_COMMERCIAL_STATUS → STATUS-PRE-COMMERCIAL
└── BENCHMARKED_AGAINST
    ├── COMP-CATL-EV-001 Shenxing PLUS
    ├── COMP-BYD-EV-001 Blade Battery
    └── COMP-LGES-EV-002 LFP Pouch

PROD-SKON-EV-010 Prismatic Platform
├── HAS_FORM_FACTOR → FORM-PRISMATIC
├── HAS_VARIANT → PROD-SKON-EV-008 Pouch-Integrated Prismatic
├── HAS_VARIANT → PROD-SKON-EV-009 On-Vent Prismatic
└── HAS_COMMERCIAL_STATUS → STATUS-PRE-COMMERCIAL

PROD-SKON-EV-011 Cylindrical Platform
├── HAS_FORM_FACTOR → FORM-CYLINDRICAL
└── HAS_COMMERCIAL_STATUS → STATUS-EXPLORATORY
```

SK온 각형 제품군은 공식 시제품과 개발 프로그램이 확인되지만 양산계약은 확인되지 않았다. 원통형 플랫폼은 공개자료상 탐색단계로 유지한다. On-Vent와 파우치 통합 각형 제품의 기술 존재는 공식 자료로 확인된다. ([ASK Inno][3])
