# D05-57. Human-Readable IP Strategy Report

## 57.1 Executive Summary

SK온의 공개 R&D·IP 포트폴리오는 크게 네 가지 축으로 정리된다.

```text
1. 상용 리튬이온 경쟁력
   ├─ 하이니켈 양극
   ├─ 급속충전 전극
   ├─ 실리콘 다층 음극
   └─ Z-Folding

2. 안전·팩 아키텍처
   ├─ 열 차단
   ├─ 화염 차단
   ├─ 가스 배출
   ├─ On-Vent
   └─ CTP 열경로

3. 배터리 인텔리전스
   ├─ BMS 보정
   ├─ SOH 추정
   ├─ AI 이상감지
   ├─ EIS
   └─ Battery Ledger

4. 차세대 배터리
   ├─ 황화물 복합양극
   ├─ 리튬메탈 계면
   ├─ 산화물 광소결
   ├─ LLZO
   └─ 차세대 양극
```

## 57.2 공개 포트폴리오상 강점

### ① 제품과 직접 연결되는 시스템 IP

SK온은 소재 조성만이 아니라 셀·팩·BMS 수준의 시스템 특허를 보유한다. 급속충전 전극과 다층 실리콘 음극은 SF 계열 제품기술과 연결되며, 열 차단·벤트·CTP 특허는 팩 안전·구조기술과 대응한다. EIS, SOH와 Battery Ledger는 ESS·BaaS·배터리 여권으로 이어질 수 있는 데이터 IP다.

### ② 안전기술의 계층화

열 차단부재, 난연·에어로젤 복합층, 파우치 배기구조, 모듈 벤트홀과 CTP 열전도경로가 서로 다른 레이어에서 형성돼 있다. 이는 안전을 단일 소재가 아니라 `감지 → 배기 → 단열 → 화염차단 → 팩 격리`로 보호하는 구조다.

### ③ 논문과 특허가 연결되는 산화물 전고체 연구

광소결 가넷 전해질 분야에서는 동일 연구자들이 논문 저자와 특허 발명자로 확인된다. 이는 학술연구가 기업 특허와 공정개발로 연결된 대표적인 공개 사례다.

### ④ 배터리 생애주기 데이터 IP

Battery Ledger, SOH 추정과 이상감지 특허를 결합하면 제조부터 차량 사용, 정비, 재사용과 재활용까지 연결할 수 있다. Battery Passport가 규제 대응을 넘어 잔존가치·보증·중고차 평가 사업으로 확장될 수 있는 기반이다.

## 57.3 핵심 취약점

### ① 소재 원천특허 의존

실리콘 복합재, 황화물 전해질과 건식전극 바인더·섬유화 분야는 외부 전문기업과 경쟁 셀기업의 특허가 밀집돼 있다. SK온이 자체 셀·공정 특허를 보유하더라도 소재 제조와 사용에 필요한 실시권을 별도로 확인해야 한다.

### ② 제품 적용근거 부족

특허와 제품기술의 구조적 유사성은 확인되지만, 공개자료에서 제품별 특허번호나 실제 청구항 실시를 직접 확인하기 어렵다. 현재 D05는 제품 적용특허가 아니라 `기술적으로 연결되는 특허군`을 제공한다.

### ③ 공식 권리상태 미검증

미국·유럽 등록공보가 확인된 사례가 있어도 현재 존속, 권리이전과 국가별 유효화를 최종 확정하지 않았다. 법적 판단이 필요한 경우 공식 등록부 감사가 선행돼야 한다.

### ④ 공동개발 IP의 계약의존성

Solid Power, PolyPlus, 대학·연구기관과의 공동연구는 기술확보에는 유리하지만 Background IP와 개량발명 권리가 복잡해진다. 기술이전이나 공동출원이 존재해도 SK온이 제3자에게 자유롭게 라이선스하거나 독자적으로 개량할 수 있다는 뜻은 아니다.

## 57.4 우선 IP 전략

### 1순위 — 건식전극 방어선 구축

범용 건식전극 조성·필름 특허와 정면으로 경쟁하기보다 SK온의 파일럿 데이터에 기반한 인라인 센싱, 접착력·기공률 예측, 공정이력과 폐루프 캘린더링을 특허와 영업비밀로 보호해야 한다.

### 2순위 — 전고체 계면·검사 IP

황화물 조성 자체보다 복합양극 공정, 리튬 접촉손실, 계면공극 검사, 압력분포와 수명예측을 권리화하는 것이 차별화 가능성이 높다. 파일럿 라인에서 생성되는 결함·수명 상관데이터는 외부 장비사와 공유범위를 엄격히 통제해야 한다.

### 3순위 — On-Vent 제조 IP 확대

현재 공개특허는 노치 형상과 파열압력 구조에 강하다. 다음 단계는 레이저 가공조건, 인라인 깊이 측정, 파열압력 예측과 자동 보정의 폐루프 제조 IP다.

### 4순위 — Battery Passport의 개인정보 보호

기존 Battery Ledger를 소재 원산지·탄소정보·재활용 이력까지 확장하되, 원데이터를 모두 공유하지 않고 SOH·잔존가치만 증명할 수 있는 선택적 공개구조를 개발해야 한다.

### 5순위 — AI Researcher 발명기록

AI가 생성한 설계후보와 인간 연구자의 기술적 기여를 구분할 수 있는 발명기록 시스템이 필요하다. 이는 특허 발명자 판단뿐 아니라 설계결과 재현성과 고객 RFQ 기밀보호에도 필요하다.

## 57.5 FACT·ANALYSIS·HYPOTHESIS

**FACT**

SK온 공개 포트폴리오에는 급속충전 전극, 건식전극, Z-Folding, 열 차단·벤트·CTP, SOH·Battery Ledger·AI 이상감지·EIS와 전고체 관련 특허군이 존재한다. 차세대 소재 분야에서는 다수의 공동 논문과 일부 공동출원도 확인된다.

**ANALYSIS**

SK온의 상대적 강점은 소재 하나의 독점보다 셀·팩·진단을 연결하는 응용·시스템 IP에 있다. 원천 소재·공정이 밀집된 분야에서는 외부 라이선스와 내부 응용특허를 결합하는 전략이 필요하다.

**HYPOTHESIS**

SK온이 `기술 → 논문 → 특허 → 파일럿 실험 → 고객 샘플 → 제품`의 연결정보를 하나의 지식그래프로 관리하면 중복 연구와 특허 누락을 줄이고, 외부협력에서 개량발명과 Background IP를 더 정확히 구분할 수 있다.
