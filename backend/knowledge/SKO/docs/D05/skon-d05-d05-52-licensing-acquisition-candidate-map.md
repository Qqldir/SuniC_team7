# D05-52. Licensing·Acquisition Candidate Map

## 52.1 협력모델 분류

```yaml
external_ip_strategy:

  MATERIAL_SUPPLY_WITH_LICENSE:
    use_when:
      - Material cannot be economically designed around
      - Supplier patent is inseparable from supplied material

  TECHNOLOGY_LICENSE:
    use_when:
      - Mature process or composition is required
      - Internal development time is longer than market window

  JOINT_DEVELOPMENT:
    use_when:
      - SK On possesses application data
      - Partner possesses generic material or equipment IP

  IP_ACQUISITION:
    use_when:
      - Technology is strategically core
      - Patent owner has limited commercialization capacity
      - Exclusive access creates meaningful differentiation

  CROSS_LICENSE:
    use_when:
      - Both parties own blocking patents
      - Joint customer program requires mutual implementation

  TRADE_SECRET_PARTNERSHIP:
    use_when:
      - Process window is more valuable than published claims
      - Patent disclosure would reveal reproducible recipe
```

Solid Power처럼 전해질과 셀 공정에 모두 권리층을 가진 기업과의 계약은 소재 구매계약만으로는 충분하지 않다. 셀 제조 실시권, 공정개선 특허, 제3자 전해질 사용권과 계약종료 후 권리를 별도로 규정해야 한다. ([구글 특허][11])

실리콘 소재기업과의 협력에서는 소재 특허의 사용권 외에도 공급중단 시 대체공급사에서 유사 소재를 사용할 수 있는지, 해당 소재를 SK온 다층전극에 적용하면서 발생한 개량발명의 소유권이 누구에게 귀속되는지를 핵심 계약조건으로 설정해야 한다. ([구글 특허][4])
