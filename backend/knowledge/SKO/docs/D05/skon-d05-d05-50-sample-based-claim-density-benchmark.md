# D05-50. Sample-Based Claim-Density Benchmark

## 50.1 기술영역별 밀도

| 기술영역             | 표본 Claim Density | 핵심 판단                            |
| ---------------- | ---------------: | -------------------------------- |
| 황화물 전고체          |              5/5 | 소재·합성·계면·전극·셀·압력까지 밀집            |
| 실리콘 급속충전         |              5/5 | 소재기업과 셀기업 권리층 동시 존재              |
| 건식전극             |              5/5 | 바인더·섬유화·필름·롤·연속장비까지 밀집           |
| 열전파 방지           |              4/5 | 소재·단열·벤트·가스경로·팩구조 중첩             |
| EIS 진단           |              4/5 | 측정회로·여기신호·모델·상태추정 중첩             |
| Battery Passport |              3/5 | 배터리 ID는 중간, 범용 제품 Passport는 확대 중 |

**ANALYSIS**

SK온은 열전파·EIS·Battery Ledger처럼 배터리 제품과 직접 연결되는 응용·시스템 IP는 상대적으로 강하지만, 건식전극 바인더나 실리콘 복합소재, 황화물 전해질 합성처럼 소재·원천공정 IP에서는 외부기업의 권리층을 함께 사용해야 할 가능성이 높다. 이는 향후 협력계약에서 단순 소재공급뿐 아니라 `제조 실시권`, `개량발명`, `다른 공급사의 대체소재 사용권`을 확보해야 한다는 의미다. ([구글 특허][3])
