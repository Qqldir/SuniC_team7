# 13. 브랜드 정체성

## 13.1 브랜드명 의미

| 항목          | 내용                |
| ----------- | ----------------- |
| Brand       | SK on             |
| 핵심 단어       | ON                |
| 의미 1        | 에너지와 미래를 켜다       |
| 의미 2        | 사업과 혁신이 계속 이어진다   |
| 출범 맥락       | 독립 배터리기업의 시작과 지속성 |
| Fact Status | 공식 설명 기반          |

브랜드명은 배터리를 통해 깨끗하고 편리한 세상을 만들고 글로벌 선도기업으로 성장한다는 지향을 반영한다. ([연합뉴스][1])

## 13.2 브랜드 사용 규칙

* 국문 본문에서는 `SK온` 사용
* 영문 본문에서는 `SK On` 사용
* 법적 계약·법인 데이터에서는 `SK On Co., Ltd.` 사용
* 로고 표기는 공식 CI 규정에 따름
* `SK ON`, `SKON`, `SK-On`은 검색 alias로 저장하되 공식 표기로 출력하지 않음
