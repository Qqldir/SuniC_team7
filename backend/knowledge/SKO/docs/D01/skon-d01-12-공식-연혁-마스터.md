# 12. 공식 연혁 마스터

## 12.1 배터리사업 형성기

| 시기       | 이벤트                     | 상태    |
| -------- | ----------------------- | ----- |
| 2010년 전후 | 기아 레이 전기차 배터리 공급업체 선정   | 공식 연혁 |
| 2011년    | Daimler 관련 배터리 공급 기반 확보 | 공식 연혁 |
| 2010년대   | 전기차용 배터리 기술·고객·양산역량 확대  | 공식 연혁 |
| 2017년 이후 | 미국·유럽·중국 중심 글로벌 생산 확대   | 공식 연혁 |

SK온 공식 연혁은 초기 전기차 배터리 공급 성과 이후 주요 전기차 시장에 현지 생산기지를 확대해 글로벌 배터리 기업으로 성장한 흐름을 제시한다. ([SK On][5])

## 12.2 독립법인 및 통합법인 전환기

| 날짜         | 이벤트                     | Event ID            |
| ---------- | ----------------------- | ------------------- |
| 2021-10-01 | SK온 공식 출범               | `EVT-SKON-2021-001` |
| 2025-02    | SK트레이딩인터내셔널·SK엔텀과 합병 완료 | `EVT-SKON-2025-001` |
| 2025-11-01 | SK엔무브와 합병 완료            | `EVT-SKON-2025-002` |
| 2025-11    | 통합 SK온 공식화              | `EVT-SKON-2025-003` |
| 2025-10~11 | 이용욱 사장 선임 및 각자대표 체계 구축  | `EVT-SKON-2025-004` |

SK온은 2025년 두 차례의 주요 합병을 거치면서 기존 배터리 전문법인에서 배터리·트레이딩·에너지효율화 사업을 포괄하는 통합사업체로 기업 정체성이 확대됐다. ([ASK Inno][9])
