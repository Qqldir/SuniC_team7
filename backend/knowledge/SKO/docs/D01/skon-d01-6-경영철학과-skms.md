# 6. 경영철학과 SKMS

SK온은 SK그룹의 공통 경영철학인 SKMS를 기업 운영의 기반으로 사용한다. SKMS는 SK 계열회사가 공동으로 적용하는 경영관리 체계이며, 기업의 지속적 성장과 이해관계자의 행복을 함께 추구하는 SK 고유의 경영철학으로 기능한다. SK온 공식 홈페이지도 회사 소개 체계 내에 `Management Philosophy (SKMS)`를 독립 항목으로 두고 있다. ([SK On][8])

### 경영철학 엔티티

```yaml
philosophy_id: PHIL-SKMS-001
name: SK Management System
abbreviation: SKMS
owner_group: SK Group
applied_company: SK On
type: group_management_philosophy
fact_status: official_fact
```

### 주요 관계

```text
SK_ON — APPLIES_MANAGEMENT_PHILOSOPHY → SKMS
SKMS — SHARED_ACROSS → SK_GROUP_AFFILIATES
```

SKMS의 세부 구성과 SUPEX 추구, 이해관계자 행복, 자율·책임경영 등은 그룹 공통 도메인에서 관리하되, SK온 관련 적용 사례는 향후 조직문화 및 운영 도메인과 연결한다.
