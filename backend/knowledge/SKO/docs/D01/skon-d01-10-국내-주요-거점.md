# 10. 국내 주요 거점

## 10.1 서울 사업장

| 필드      | 데이터                      |
| ------- | ------------------------ |
| Site ID | `SITE-SKON-KR-SEOUL-001` |
| 명칭      | SK온 서울 사업장 / 관훈캠퍼스       |
| 주소      | 서울특별시 종로구 인사동7길 32       |
| 유형      | 본사·경영·사업 운영 거점           |
| 상태      | 운영                       |
| 근거      | 공식 홈페이지                  |

SK온 공식 홈페이지는 서울 사업장을 종로구 인사동7길 32에 위치한 국내 사업장으로 안내한다. 공식 기업행사와 CEO 타운홀, CEO Recognition 등도 관훈캠퍼스에서 개최됐다. ([SK On][2])

| 필드      | 데이터                        |
| ------- | -------------------------- |

## 10.3 서산 생산거점

SK온 공식 연혁과 국내 사업장 체계에는 충남 서산의 배터리 생산거점이 포함된다. 서산 공장은 SK 배터리사업의 국내 양산 기반으로 기능해 왔다. 세부 생산능력과 제품구성은 D07 Manufacturing Assets & Sites에서 시점별 수치와 함께 별도로 관리한다. ([SK On][5])
