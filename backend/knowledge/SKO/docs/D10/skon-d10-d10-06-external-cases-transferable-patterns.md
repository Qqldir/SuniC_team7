## D10-06 External Cases & Transferable Patterns

| Case ID | 외부 사례 | 확인된 방식 | SK온 적용 포인트 |
|---|---|---|---|
| `CASE-D10-01` | CATL All-domain Portfolio | 2025년 661GWh 판매, EV·ESS 동시 1위 Claim, 다중 화학계 | 시장별 단일제품 최적화가 아닌 Chemistry–Application Portfolio 운영 |
| `CASE-D10-02` | CATL Naxtra·Dual-Power | Na-ion과 LFP/NCM을 조합하고 2026년 GWh급 양산 추진 | 원료가격·저온·수명 요구별 Multi-chemistry Architecture 검토 |
| `CASE-D10-03` | CATL Battery Swap Service | 2025년 말 1,325개 Swap Station과 OEM 협력 | Cell 판매 외 Asset·Service Data 기반 Business Model 탐색 |
| `CASE-D10-04` | LGES EV→ESS Capacity Reallocation | 기존 EV Capacity를 ESS로 재배분, 북미 현지 ESS 확대 | SK온 Commerce 등 전환 시 설비·승인·Margin 통합 의사결정 |
| `CASE-D10-05` | Samsung SDI AI Data Center Portfolio | ESS·UPS·BBU를 고출력·안전·현지생산으로 연결 | Hyperscaler 수요를 Grid ESS와 별도 Duty-cycle로 Segmentation |
| `CASE-D10-06` | BYD 12.5GWh Grid Project | Saudi Electricity와 초대형 BESS Project 계약 | Utility·Developer·EPC·PCS·EMS를 포함한 Project Ecosystem 필요 |
| `CASE-D10-07` | IEA가 지적한 비중국 생산성 과제 | 중국 가격우위와 미·EU 공급망 집중 위험 병존 | Localization Premium을 원가·보조금·회복탄력성으로 동시 평가 |

CATL은 Naxtra Sodium-ion, LFP·NCM 결합형 Dual-Power, Battery Swap Network를 하나의 Portfolio로 확장하고 있다. 이는 모든 Segment에 동일 Chemistry를 적용하기보다 원료·온도·충전·수명 제약을 기준으로 Cell Architecture를 조합하는 접근이다. ([CATL Naxtra](https://www.catl.com/en/news/6401.html), [CATL Multi-Chemistry 2026](https://www.catl.com/en/news/6811.html))

BYD Energy Storage의 12.5GWh Saudi Electricity 계약은 ESS 경쟁단위가 개별 Cell을 넘어 Project Bankability·System Integration·납기·현장운영으로 이동하고 있음을 보여준다. SK온은 직접 통합범위를 무조건 확대하기보다 D13에서 PCS·EMS·EPC·O&M Partner 구조를 비교해야 한다. ([BYD 12.5GWh BESS](https://www.bydglobal.com/en/news/2025-02-17/BYD-Energy-Storage-Signed-World%E2%80%99s-Largest-Grid-scale-Battery-Storage-Projects-of-12.5GWh))
