## D17-09 Value Measurement & Double-Count Control

### 1. 공통 가치 단위

```text
판매 가능한 합격량 = Customer-accepted kWh
원가 = KRW / Customer-accepted kWh
품질손실 = Scrap + Rework + Hold + Claim + Warranty + Recall + Lost Throughput
현금가치 = 실제 회수·절감·지연·회피 현금의 시점조정 값
안전가치 = 사고확률의 임의 화폐화가 아니라 Barrier·Exposure·Response KPI와 별도 보고
```

### 2. 이중계상 예시

- `수율향상`과 `원가절감`이 같은 Scrap 감소에서 발생하면 한 Benefit Group으로 묶는다.
- `45X 회계인식`, `신청액`, `현금수령`, `Clawback Risk`를 네 번의 편익으로 더하지 않는다.
- `CAPEX 회피`, `감가상각 감소`, `현금유출 감소`가 같은 투자중단에서 발생하면 NPV 한 건으로 계산한다.
- `Recall 범위 축소`와 `Warranty 절감`은 동일 Population·Remedy를 기준으로 중복을 제거한다.
- 경쟁사·Vendor Reference ROI는 Benefit이 아니라 Prior 또는 검증가설로만 사용한다.
