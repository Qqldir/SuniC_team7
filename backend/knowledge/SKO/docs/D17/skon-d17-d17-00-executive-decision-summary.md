# SK온 D17 Open-Innovation Opportunity Portfolio & AI Task Recommendation

**Version 1.1 / 기준일: 2026-08-03 / D00 교차검수 반영 분석 문서**

- 상위 목적: D01~D16에서 확인된 사실·Pain Point·O/I Seed·외부 Capability를 중복 제거하고, SK온이 실제로 `검증 → PoC → 확장 → 중단`할 수 있는 60개 과제 포트폴리오와 AI 추천·통제체계를 제시한다.
- 문서 성격: 공개자료와 선행 도메인 분석에 기반한 사전심사안이다. SK온 내부 KPI, 예산, 계약, 데이터 접근권, 투자·구매·법률·세무·품질·안전 승인을 대신하지 않는다.
- 핵심 원칙: 유명 공급사나 최신 AI 기술에서 출발하지 않고, **검증된 문제와 의사결정에서 출발한다.**

## D17-00 Executive Decision Summary

### 1. 최종 포트폴리오

| 구분 | 수량 | 의미 |
|---|---:|---|
| 원천 O/I Seed | 279개 | D03 10개·D04 47개·D05 18개·D06 49개·D07 21개·D08 15개·D09 14개·D10~D16 각 15개. D05 v2.0 복구로 18개가 추가됐으며, 동일 문제·데이터·Owner가 반복돼 단순 실행은 금지한다. |
| 최종 과제 | 60개 | 12개 포트폴리오 × 5개 과제로 재설계한 실행 후보 |
| `P0` | 20개 | 가치와 도메인 연결성이 높아 G0·G1 검증을 먼저 시작할 과제 |
| `P1` | 24개 | 선행 데이터·권리·조직조건을 닫은 뒤 PoC할 과제 |
| `P2` | 16개 | 기술실사·시장관찰·장기 Option으로 관리할 과제 |

### 2. 가장 먼저 착수할 5개 Foundation

1. `D17-OI-001` Opportunity Portfolio Control Tower
2. `D17-OI-002` External Evidence & Reference Validation Agent
3. `D17-OI-003` PoC-to-Scale Stage-Gate Orchestrator
4. `D17-OI-004` Multi-Vendor Battery Data Sandbox
5. `D17-OI-006` Material-to-Cell Manufacturing Data Backbone

이 다섯 과제는 다른 과제의 성과를 대신 만들지 않는다. 다만 **문제·근거·데이터·권리·Baseline·중단기준이 없는 과제가 생산망과 예산에 진입하는 것을 막는 공통 기반**이다.

### 3. 1차 Value Wave

Foundation과 병행할 실제 가치 검증은 다음 다섯 과제로 제한한다.

- `D17-OI-007` Yield-to-Margin Causal AI
- `D17-OI-008` Formation–Aging Flow & Energy Optimizer
- `D17-OI-011` Customer-Qualified Capacity Ledger
- `D17-OI-021` Qualified-kWh Cost Digital Twin
- `D17-OI-036` PFE/MACR & 45X Qualified-kWh Evidence Engine

초기에는 한 개 공장·한 개 Line·한 개 Cell Revision·한 개 고객 Program처럼 경계를 좁힌다. 공개자료만으로 Plant, Line, 기간은 지정하지 않는다.
