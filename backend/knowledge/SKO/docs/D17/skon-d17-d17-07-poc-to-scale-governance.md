## D17-07 PoC-to-Scale Governance

### 1. G0~G8

| Gate | 필수 산출물 | 통과 | 중단 |
|---|---|---|---|
| G0 Problem Proof | Pain Point·Owner·분모·Baseline | 문제와 손실 재현 | Solution-first·무주인 과제 |
| G1 Data/IP/Security | Data Map·권리·Cyber·고객/JV 승인 | 최소권한·삭제·Export·Rollback | 무제한 학습·권리 불명 |
| G2 Offline Back-test | 과거 Data·Leakage Test·기존 Rule 비교 | 유의한 개선과 안정성 | 미래정보 Leakage·Label 오류 |
| G3 Shadow Mode | 실제 운영 예측·Drift·Latency | 작업 영향 없이 재현 | Alert Flood·안전 Guardrail 미흡 |
| G4 Bounded Live PoC | 한정 Site/Line/Product·Human Approval | KPI 개선, Guardrail 유지 | 품질·안전·생산 악화 |
| G5 Independent Validation | 재무·품질·SHE·법무 독립검증 | 가치·부작용·재현성 승인 | Vendor 자체평가뿐임 |
| G6 Scale Gate | TCO·Support·Architecture·Exit | Scale Business Case | 통합·변경비가 편익 초과 |
| G7 Multi-site | 표준 Template·교육·Monitoring | Site별 Control과 성과 유지 | 예외 누적·Drift 확대 |
| G8 PIR/Exit | 가정–실제 비교·계약/모델 Update | 학습 재사용 또는 안전한 종료 | Zombie 운영 지속 |

### 2. 공통 Human Approval

- 품질 Release·Scrap Disposition·Recall 범위: Quality/Safety 책임자
- PLC·Recipe·BMS 제어변경: 제조기술·품질·OT Cyber·MOC 승인
- 세무·관세·원산지·규제 적격: 세무·통상·법무 담당자
- 계약의무·IP·Data Rights·JV 권리: 법무·IP·JV Governance
- CAPEX·Funding·Bid·Customer Commitment: 해당 투자·재무·영업 승인체계
