## D17-08 Operating Model & 12-Month Roadmap

### 1. 권장 운영조직

| 역할 | 책임 |
|---|---|
| Executive Sponsor | Portfolio 방향·예산·중단권 |
| O/I Portfolio Office | Dedupe·Stage Gate·Provider·PIR 운영 |
| Domain Product Owner | Pain Point·Workflow·현장 Adoption |
| Data/Architecture Owner | Canonical Model·API·MLOps·재사용 |
| Quality/SHE/Cyber/Legal | Hard Gate·독립검증·변경통제 |
| Finance Value Assurance | Baseline·Counterfactual·Cash·이중계상 통제 |
| Procurement/Partner Manager | RFI/RFP·TCO·SLA·Exit·Vendor Continuity |

### 2. 12개월 실행

| 기간 | 핵심 작업 | 산출물 |
|---|---|---|
| 0~2개월 | W0 001~004 G0/G1, P0 Owner·Baseline 확인 | Canonical Task Register, Hard-Gate 결과 |
| 2~4개월 | 006·011·021·031·046 Data Prototype | 최소 Entity/Relationship·권한·Quality Report |
| 4~6개월 | 007·008·009·036 Offline/Shadow | Back-test·Counterfactual·Safety Review |
| 6~9개월 | 통과 과제만 Bounded Live PoC | 독립 KPI·TCO·Stop/Scale Decision |
| 9~12개월 | 1~2개 과제 Multi-site Template, 나머지 PIR/Exit | Scale Architecture·No-Go Memory·다음 Cycle |

동시에 진행하는 Live PoC 수는 현장 Owner와 검증인력이 감당할 수 있는 범위로 제한한다. 숫자를 먼저 정하지 않고, G0/G1을 통과한 과제만 Portfolio Capacity에 포함한다.
