## D14-05 Trade, Customs & Forced-Labor Compliance

### 1. Section 301 품목별 통제

미국 USTR 발표상 중국산 Lithium-ion EV Battery는 2024년 25%, Non-EV Lithium-ion Battery와 Natural Graphite는 2026년 25%로 인상됐다. Battery Parts와 다른 Critical Minerals도 품목·시행연도가 다르다. `중국산 배터리 관련품 전체 25%`처럼 일반화하지 않고 HTSUS·원산지·시행일·Exclusion을 거래별로 저장한다. ([USTR Section 301 Modification](https://ustr.gov/about-us/policy-offices/press-office/press-releases/2024/may/us-trade-representative-katherine-tai-take-further-action-china-tariffs-after-releasing-statutory))

### 2. UFLPA Evidence Pack

CBP의 2026 Importer Guidance는 High-priority Sector에 대해 공급망 추적을 강조한다. 미국 수입 Shipment는 다음 자료를 사전에 묶어야 한다. ([CBP Importer Guidance](https://www.cbp.gov/sites/default/files/2026-06/fld_importer_guidance_final_06092026_0.pdf))

```text
Mine / Brine / Feedstock
→ Concentrator / Refiner / Processor
→ pCAM / CAM / AAM / Foil / Separator / Electrolyte
→ Cell / Module
→ Exporter / Importer of Record
→ Commercial Invoice / PO / Packing List / B/L / COO
→ Lot Mass Balance / Payment / Production Record
→ Admissibility Decision / Detention / Release
```

PFE Tax 판정과 UFLPA 수입허용 판정은 목적과 법적 기준이 다르다. `PFE Pass`가 강제노동 Risk 해소를 뜻하지 않으며, 중국 밖에서 가공했다는 사실도 Upstream 추적을 면제하지 않는다.

### 3. EU CBAM 경계

EU CBAM의 2026년 Definitive Regime은 Cement, Iron & Steel, Aluminium, Fertiliser, Electricity, Hydrogen 중 Annex I CN Code 품목에 적용된다. 완성 Battery가 자동으로 CBAM 대상이라는 뜻은 아니다. Aluminum Foil·Housing·금속 중간재는 실제 CN Code와 Importer 구조로 검토하고, Battery 탄소발자국 규정과 CBAM을 이중 Count하지 않는다. ([European Commission CBAM](https://taxation-customs.ec.europa.eu/carbon-border-adjustment-mechanism_en))

### 4. Landed-cost Waterfall

```text
Supplier Price
+ Freight / Insurance
+ Ordinary Duty
+ Section 301 / Trade Remedy
+ CBAM Certificate Cost if In Scope
+ Brokerage / Detention / Premium Freight
+ Compliance Evidence and Verification Cost
− Drawback / Exclusion / Preferential Origin Benefit
= Policy-adjusted Landed Cost
```
