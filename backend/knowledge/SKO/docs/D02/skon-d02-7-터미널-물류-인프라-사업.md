> SK온 · D02 사업 포트폴리오

# 7. 터미널·물류 인프라 사업

## 7.1 사업 정의

| 필드          | 데이터                     |
| ----------- | ----------------------- |
| Business ID | `BUS-SKON-TERMINAL-001` |
| 전신 사업       | SK엔텀 관련 사업              |
| 사업유형        | 저장·출하·물류 인프라            |
| 주요 자산       | 탱크터미널 및 물류시설            |
| 주요 고객       | 정유·화학·트레이딩 사업자          |
| 사업단계        | 성숙 인프라                  |
| 포트폴리오 역할    | 트레이딩 지원·안정적 인프라         |

통합 SK온 연결 범위에 SK엔텀이 포함된 점은 공식 실적자료에서 확인된다. 다만 터미널의 정확한 저장용량·시설·서비스 범위는 D07과 별도 기업·시설 자료에서 검증해야 한다. ([ASK Inno][2])

### 기능 구조

```text
Cargo Receipt
→ Storage
→ Inventory Management
→ Quality Management
→ Transfer
→ Shipment
→ Customer Delivery
```

### O/I 연관영역

* 탱크 상태 모니터링
* 누출 감지
* 예지보전
* 디지털 트윈
* 에너지 사용 최적화
* 선박·탱크 스케줄 최적화
* 안전관리 자동화

위 항목들은 터미널산업의 일반적 혁신영역이며, SK온 내부의 확정 과제가 아니다.
