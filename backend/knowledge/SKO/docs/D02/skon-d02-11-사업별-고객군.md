# 11. 사업별 고객군

| Customer Segment ID      | 고객군         | 관련 사업             |
| ------------------------ | ----------- | ----------------- |
| `CUS-OEM`                | 완성차 제조사     | EV Battery        |
| `CUS-EV-STARTUP`         | 전기차 스타트업    | EV Battery        |
| `CUS-COMMERCIAL-VEHICLE` | 상용차·특수차 제조사 | EV Battery        |
| `CUS-UTILITY`            | 전력회사·발전사    | ESS               |
| `CUS-BESS-DEVELOPER`     | BESS 개발사업자  | ESS               |
| `CUS-RENEWABLE`          | 재생에너지 개발사   | ESS               |
| `CUS-C&I`                | 상업·산업 고객    | ESS               |
| `CUS-MOBILITY`           | 모빌리티 플랫폼    | BaaS              |
| `CUS-FINANCE`            | 리스·금융·보험    | BaaS              |
| `CUS-RECYCLER`           | 재사용·재활용 사업자 | BaaS              |
| `CUS-REFINER`            | 정유기업        | Trading           |
| `CUS-PETROCHEM`          | 석유화학기업      | Trading·Terminal  |
| `CUS-LUBRICANT`          | 윤활유 제조사     | Lube Base Oil     |
| `CUS-DATACENTER`         | 데이터센터 운영사   | Immersion Cooling |
| `CUS-INDUSTRIAL`         | 산업설비 운영사    | Energy Efficiency |

고객군 목록은 공식 사업내용과 산업구조를 결합한 표준분류다. 특정 고객사가 실제 고객인지 여부는 D08에서 공식 공급계약을 확인한 뒤 기록한다.
