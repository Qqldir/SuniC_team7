> SK온 · D02 사업 포트폴리오

# 10. 사업 포트폴리오의 성숙도

## 10.1 성숙도 기준

| Level                   | 정의        |
| ----------------------- | --------- |
| `L1 Research`           | 기초 연구     |
| `L2 Development`        | 기술·제품 개발  |
| `L3 Demonstration`      | 실증·PoC    |
| `L4 Initial Commercial` | 초기 계약·판매  |
| `L5 Scale-up`           | 생산·수주 확대  |
| `L6 Mature`             | 안정적 상업 운영 |
| `L7 Transformation`     | 사업 전환·재편  |

## 10.2 사업별 평가

| 사업          | 성숙도   | 근거 상태                  |
| ----------- | ----- | ---------------------- |
| NCM 전기차 배터리 | L5–L6 | 글로벌 양산·공급              |
| LFP 전기차 배터리 | L2–L4 | 개발·시장확대                |
| NCM ESS     | L4–L5 | 공식 상업용 ESS             |
| LFP ESS     | L4–L5 | 1GWh 공급계약·현지생산 계획      |
| VIB ESS     | L2–L3 | 공동개발                   |
| BaaS        | L2–L4 | 공식 플랫폼·협력사례            |
| 배터리 재사용     | L2–L4 | 공식 서비스 범위, 상용 규모 별도 확인 |
| 배터리 재활용     | L2–L4 | 공식 서비스 범위, 수행구조 별도 확인  |
| 트레이딩        | L6    | 기존 성숙사업                |
| 터미널         | L6    | 기존 인프라사업               |
| 윤활기유        | L6    | 기존 성숙사업                |
| 배터리 액침냉각    | L2–L4 | 기술공개·사업 연계             |
| VIB         | L2    | 공동개발                   |

성숙도는 공식 사실을 기초로 한 데이터베이스용 분석값이므로 `analysis_classification`으로 관리한다.
