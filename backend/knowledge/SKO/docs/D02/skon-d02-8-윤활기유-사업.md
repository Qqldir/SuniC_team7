# 8. 윤활기유 사업

## 8.1 사업 정의

| 필드          | 데이터                |
| ----------- | ------------------ |
| Business ID | `BUS-SKON-LBO-001` |
| 운영 단위       | SK엔무브 관련 CIC       |
| 주요 제품       | 윤활기유 및 관련 제품·솔루션   |
| 주요 고객       | 글로벌 윤활유 제조사·산업 고객  |
| 사업유형        | B2B 제조·판매          |
| 사업단계        | 성숙사업               |
| 포트폴리오 역할    | 수익기반·에너지효율 사업      |

기존 SK엔무브의 사업은 윤활기유와 윤활 관련 제품을 기반으로 하며, SK이노베이션의 과거 지속가능경영 자료는 연비 개선과 배출저감 효과를 가진 고품질 윤활기유를 친환경 제품·서비스 사례로 제시했다. ([SK Innovation][15])

---

## 8.2 포트폴리오 연계

🟢 **Fact**

SK엔무브와 SK온의 통합은 배터리사업과 열관리·윤활기유 기반 에너지효율 사업을 하나의 법인 아래 결합하는 구조다. SK이노베이션은 2025년 공식 실적자료에서 액침냉각과 배터리사업 간 시너지를 통합의 주요 방향으로 제시했다. ([ASK Inno][2])

🔵 **Analysis**

윤활기유사업 자체는 전기차 배터리 제조와 다른 고객·설비·원재료 구조를 가지지만, 열관리 유체와 액침냉각 분야에서는 배터리·데이터센터·산업 냉각과 접점이 형성될 수 있다.
