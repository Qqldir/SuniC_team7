# 5. 배터리 인접 사업

## 5.1 열관리와 액침냉각

SK온은 2025년 공식 전시에서 전기차 배터리용 액침냉각 기술을 선보였다. 액침냉각은 배터리 셀 또는 시스템을 비전도성 냉각유체로 직접 냉각하는 방식으로, 열관리 성능과 안전성 향상을 목표로 한다. 이 사업은 2025년 SK엔무브와의 통합 이후 배터리 기술과 열관리 유체·에너지효율 사업을 연결할 수 있는 대표적인 인접영역이다. ([SK On][14])

### 사업 상태

```yaml
business_id: BUS-SKON-THERMAL-001
business_name: Battery Thermal Management
scope:
  - EV battery immersion cooling
  - thermal management fluid
  - battery system cooling
portfolio_status: emerging_adjacent_business
fact_status: official_technology_and_strategic_expansion
```

---

## 5.2 제조·배터리 데이터 사업

SK온이 제조 AI, 배터리 상태 분석, BMS 및 수명관리 역량을 활용하는 것은 제품 판매를 지원하는 내부역량인 동시에 장기적으로 데이터 기반 서비스사업의 기반이 될 수 있다.

다만 `AI 기반 제조 최적화 서비스`나 `외부 고객 대상 데이터 플랫폼 판매`가 공식 독립사업으로 확인된 것은 아니므로 다음과 같이 분리한다.

| 영역              | 현재 분류    |
| --------------- | -------- |
| 자체 공장 제조 AI     | 내부 운영역량  |
| 배터리 상태·수명 진단    | BaaS 서비스 |
| 고객 대상 BMS 기능    | 제품·솔루션   |
| 외부 제조사 대상 AI 판매 | 미확인      |
| 배터리 데이터 플랫폼 수익화 | 성장 가설    |
