# 12. 사업별 수익모델

## 12.1 공식 확인 수준

| 사업                 | 주요 수익원           | Fact Status                  |
| ------------------ | ---------------- | ---------------------------- |
| EV Battery         | 셀·모듈·팩 판매 및 공급계약 | Official General             |
| ESS                | 셀·모듈·BESS 공급     | Official                     |
| BaaS               | 생애주기 서비스         | Official Scope / 상세 수익구조 미확인 |
| Trading            | 매입·판매·거래 마진      | Industry-based / 세부 공시 필요    |
| Terminal           | 저장·하역·물류 서비스     | Industry-based / 세부 공시 필요    |
| Lube Base Oil      | 윤활기유 판매          | Official General             |
| Thermal Management | 냉각유체·솔루션 공급      | Emerging / 계약별 확인            |

## 12.2 전기차 배터리

```text
Customer Nomination
→ Product Development
→ Supply Contract
→ Cell/Module/Pack Delivery
→ Revenue Recognition
→ Quality and Warranty Obligations
```

전기차 배터리는 고객사와의 공급계약을 통해 제품을 납품하고 매출을 인식하는 제조업 모델이 중심이다. 가격구조, 원재료 연동, 보증과 인센티브는 D11에서 관리한다.

## 12.3 ESS

```text
Project Contract
→ Product Manufacturing
→ BESS Delivery
→ Possible Integration Support
→ Possible Lifecycle Management
```

2025년 Flatiron 프로젝트는 1GWh의 컨테이너형 LFP BESS 공급계약으로 공식 확인된다. 추가 6.2GWh는 우선협상권이므로 확정 매출로 처리하지 않는다. ([ASK Inno][10])

## 12.4 BaaS

BaaS는 제품의 일회성 판매보다 배터리 데이터와 생애주기를 기반으로 반복적 서비스를 창출할 가능성이 있다. 다만 공식 홈페이지는 서비스 범위를 설명할 뿐, 각 서비스의 과금구조와 매출기여도를 공개하지 않는다. 따라서 구체적 수익모델은 `hypothesis`로 관리한다. ([SK On][11])
