## D13-06 Change, Dispute, Exit & Transition Control

### 1. Contract Change Lineage

```text
Original Agreement
→ Amendment / Statement of Work / Purchase Order
→ Side Letter / Waiver / Deviation Approval
→ Operational Implementation
→ Financial·Capacity·IP·Risk Impact
→ Expiry / Reversal / Permanent Baseline
```

변경은 문서번호뿐 아니라 영향을 받은 `volume`, `price`, `line`, `milestone`, `IP`, `liability`, `guarantee`, `termination right`에 연결한다. 구두합의나 회의록은 권한·법적효력을 Legal이 확인하기 전까지 `UNVERIFIED_OPERATIONAL_COMMITMENT`로 둔다.

### 2. JV Separation Checklist

| Workstream | 종료·분리 시 확인사항 |
|---|---|
| Corporate | 지분 Redemption·이사 사임·권한·법인명·License |
| Asset | 토지·건물·설비·재고·Spare·담보·Lease |
| Debt/Support | 차입·Note·보증·담보·Capital Call·Shareholder Loan |
| Commercial | 고객·공급사·PO·가격·Capacity·Transition Supply |
| Technology | IP·Know-how·Software·Data·도면·Trade Secret 반환/보존 |
| People | 고용승계·비자·연금·노조·파견인력·Retention |
| Policy | Grant·Tax Credit·고용·투자 Covenant·Clawback |
| Liability | Warranty·Recall·환경·세금·소송·보험·Indemnity |
| Systems | ERP·MES·QMS·PLM·OT 계정·Cyber·Record Retention |

BOSK 사례의 핵심은 `JV가 끝났다`가 아니라 Ford 지분 Redemption, Capital Commitment 종료, Kentucky 자산·관련부채와 38.0504억달러 Note 인수, 보증해제, Tennessee 잔존이 같은 Closing에 연결됐다는 점이다. D13 내부 원장은 Closing Deliverable 하나라도 빠지면 `ORPHAN_OBLIGATION`으로 경보해야 한다. ([Ford 8-K](https://www.sec.gov/Archives/edgar/data/37996/000003799626000093/f-20260520.htm))

### 3. 분쟁 Early Warning

- Milestone 증빙 제출 지연 또는 상대방 반복 반려
- Forecast 급락과 Capacity Reservation·최소구매의 불일치
- Engineering Change가 가격·보증·납기를 변경했으나 Amendment 미체결
- Capital Call·Service Fee·Royalty·Reimbursement의 기한초과
- 공동개발 데이터·Foreground IP·직원 Know-how 사용범위 이견
- Covenant·보증·정부지원의 Change of Control Consent 누락
- Notice·Cure Period 만료 임박, Waiver 갱신 누락

AI는 이상징후와 관련 Clause를 제시하되 Notice 발송, Waiver 승인, 분쟁제기, 계약해지는 Legal·사업책임자의 승인을 거친다.
