# 23. Quality-Control Checklist

## 23.1 Factual QC

- [x] 외부 산업신호를 E&S 실제 사고로 쓰지 않음
- [x] 2026 LNG supply shock를 특정 E&S cargo 손실로 확대하지 않음
- [x] Barossa 개발단계와 2026 운영/ramp 상태를 분리
- [x] 운영 BESS MW와 개발 pipeline을 분리
- [x] H2 생산능력과 생산·판매·수금 kg을 분리
- [x] CCS announced/permitted/firm/injectivity 상태 분리
- [x] Plug Hyverse 과거 JV와 2025-12-31 지분변동 분리
- [x] 규제 in-force/future/cancelled/expired 상태 D14 상속

## 23.2 Risk QC

- [x] Risk/Issue/Incident/Loss/Control Failure 구분
- [x] Severity×Likelihood를 재무손실로 오인하지 않음
- [x] residual risk를 공개자료만으로 임의 평가하지 않음
- [x] insurance/hedge/contract 비공개 값을 추정하지 않음
- [x] leading KRI와 lagging loss KPI 분리
- [x] single-asset risk와 cross-business contagion 분리
- [x] Recovery exit criteria와 temporary workaround 분리

## 23.3 O/I QC

- [x] `Risk→Failure Mode→Pain→Seed→KPI→Gate` 연결
- [x] 80개 O/I Seed 중 D17 우선 15개 별도 표시
- [x] Priority PoC 20개에 Stop Condition 포함
- [x] Safety/Legal/Tax/CISO/Privacy Gate 포함
- [x] AI가 safety/trading/legal filing을 독자 승인하지 않도록 통제
- [x] 내부 데이터 요청 45개 정의
- [x] D16에서는 solution/vendor, D17에서는 과제 우선순위로 분리
