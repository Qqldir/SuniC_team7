## 9.2 Barossa Operating Transition

2026년 Barossa는 더 이상 단순 `개발 pipeline`이 아니다. Santos의 공식자료상 첫 LNG cargo와 이후 ramp가 확인되므로 D15는 위험단계를 아래처럼 전환한다. `[SRC-ENS-D15-0013][SRC-ENS-D15-0014]`

```text
Before first LNG:
construction → commissioning → RFSU → first gas → first LNG

After first LNG:
production ramp → reliability → cargo entitlement → operating cost → carbon compliance
→ JV distribution / long-term reservoir performance
```

## 9.3 Quynh Lap LNG-to-Power Critical Path

Quynh Lap은 D13/D14에서 개발단계·컨소시엄·2030 운영목표와 제도상 2031 임계조건을 분리했다. D15에서는 단순 `COD 지연`이 아니라 `land/site → terminal/port → LNG → power plant → grid → permits → PPA/market mechanism → finance` 의존성을 Critical Path로 저장한다.
