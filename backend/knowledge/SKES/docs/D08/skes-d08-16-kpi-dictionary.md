# 16. KPI Dictionary

## 16.1 LNG and Logistics KPIs

| KPI | 정의 | 분모/단위 | 오인 방지 |
|---|---|---|---|
| contract utilization | actual entitlement used / available right | % | 자산 가동률과 다름 |
| cargo on-time arrival | agreed window 내 도착 cargo | % | ETA forecast accuracy 별도 |
| demurrage | 계약기준 초과 대기비 | KRW/USD | 원인 귀속 필요 |
| voyage fuel intensity | fuel / delivered LNG | t/t | 날씨·route 보정 |
| cargo loss | loaded-delivered-adjustments | % | 측정차이 분리 |
| inventory cover | usable inventory / forecast demand | days | 안전재고 제외 기준 명시 |
| terminal slot adherence | confirmed slot 준수 | % | vessel/terminal 원인 분리 |
| BOG utilization | recovered/used BOG / generated BOG | % | flare와 측정오차 구분 |
| LNG landed cost | commodity+tolling+shipping+terminal | KRW/GJ | 계약기밀 |
| forecast value add | optimized baseline 대비 실제 | KRW | 시장효과 분리 |

## 16.2 Procurement and Supplier KPIs

| KPI | 정의 | 단위 | 최소 차원 |
|---|---|---|---|
| OTIF | on-time in-full receipts | % | supplier/material/site |
| PPM/NCR | defect quantity/events | ppm/count | lot/severity |
| first-pass acceptance | 재작업 없는 검수 | % | package |
| PO cycle time | requisition→PO | day | category |
| supplier lead-time bias | actual-planned | day | item/supplier |
| expedite ratio | 긴급발주/전체 | % | site/category |
| spend under contract | 계약연계 spend | % | category |
| single-source exposure | 대체 없는 P0 spend | KRW/% | asset impact |
| critical-stock service | 요청 충족 A1 품목 | % | warehouse/site |
| excess/obsolete stock | 수요 없는 재고 | KRW | reason |
| warranty recovery | 회수액/가능액 | % | supplier/asset |
| supplier ESG closure | due CAP 기한 내 종결 | % | severity |
