# D17-13 Operating Model & RACI

| 역할 | 책임 | 중단권 |
|---|---|---|
| Executive Sponsor | Portfolio 방향·예산·Scale 우선순위 | 예 |
| O/I Portfolio Office | Dedupe·Scout·Stage Gate·Provider·PIR | G0/G6 보류 |
| Domain Product Owner | Problem·Workflow·Adoption·KPI | 현장범위 보류 |
| Operations / Asset Owner | OT 접근·운전제약·실행 가능성 | Live PoC 중단 |
| SHE / Process Safety | Safety Barrier·MOC·Emergency boundary | 즉시 중단 |
| Data / Architecture | canonical ID·API·quality·reuse | Data gate 보류 |
| CISO / OT Security | zone·remote access·model/data security | 즉시 중단 |
| Legal / IP / JV | 계약·Data/IP·Consent·Reserved Matter | 법률 Gate 보류 |
| Tax / Compliance / Environment | 48E/PFE/ETS/MRV/Rule 적용 | 판정 보류 |
| Finance Value Assurance | Baseline·Counterfactual·Cash·Double-count | Benefit 승인 보류 |
| Procurement / Partner Manager | RFI/RFP·TCO·SLA·Exit·EOL | 공급사 Gate 보류 |

운영원칙은 `사업부가 문제를 소유하고, O/I가 외부역량을 연결하며, 독립기능이 Gate와 가치를 검증`하는 구조다. O/I 조직이 현장 문제의 Owner를 대신하지 않는다.
