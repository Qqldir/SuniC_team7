# D17-14 12-Month Execution Roadmap

## 1. 권장 Roadmap

| 기간 | 핵심 작업 | 대표 과제 | 산출물 |
|---|---|---|---|
| 0~2개월 | W0 Governance G0/G1 | 001·002·003·004 | Canonical Task Register·Hard Gate·Benefit Ledger·Vendor Sandbox |
| 2~4개월 | Core data/replay foundation | 006·007·011·012·016·037·046 | Asset/Contract/Data crosswalk·Baseline·Replay dataset |
| 4~6개월 | Offline/Shadow Value Wave | 008·013·021·026·027·028·036·041·047·057 | Back-test·Shadow KPI·Safety/Cyber review |
| 6~9개월 | 통과과제만 Bounded Live PoC | G3 통과 P0 일부 | Finance/SHE/Legal independent validation·TCO·Stop/Scale |
| 9~12개월 | 1~3개 Scale template + PIR | G5/G6 통과과제 | Multi-asset architecture·No-Go Memory·다음 Cycle |

## 2. Portfolio Capacity Rule

- 동시에 Live PoC 수를 문서에서 임의로 정하지 않는다.
- 각 Domain Owner·SHE·CISO·Finance 검증인력이 감당 가능한 수만 G4로 승격한다.
- G0/G1을 통과하지 않은 후보는 Portfolio Capacity를 소모하는 `Live PoC`로 세지 않는다.
- 신규 아이디어가 생기면 기존 P0보다 점수가 높다는 이유만으로 끼워넣지 않고 Dependency/Hard Gate/Owner capacity를 함께 재평가한다.
