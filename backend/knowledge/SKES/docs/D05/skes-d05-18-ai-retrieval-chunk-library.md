# 18. AI Retrieval Chunk Library

## `CHUNK-ENS-D05-001`

```yaml
question: E&S의 R&D 조직은 중앙연구소 중심인가?
answer: 공개자료상 단일 중앙연구소보다는 사업·현장·자회사·외부기관이 결합된 분산형 구조로 보는 것이 타당하다. Net Zero Technology Center 명칭은 확인되나 합병 후 상세 조직도는 내부 검증 대상이다.
confidence: MEDIUM_HIGH
source_ids: [SRC-ENS-D05-0002, SRC-ENS-D05-0004]
```

## `CHUNK-ENS-D05-002`

```yaml
question: E&S 직접 특허의 강한 영역은?
answer: 초기 표적검색에서는 도시가스 정압·계량·배관안전과 습식 CO2 포집 흡수제 운전이 선명하다.
confidence: HIGH_FOR_SAMPLED_FAMILIES
restriction: complete_portfolio_claim_prohibited
```

## `CHUNK-ENS-D05-003`

```yaml
question: EverCharge 특허는 E&S 직접 발명인가?
answer: 아니다. EverCharge 명의의 인수 자회사 IP이며 상당수 우선일은 SK E&S 인수 전이다. E&S 그룹 역량으로 연결할 수 있으나 직접발명·모회사 단독권리로 표현하면 안 된다.
confidence: HIGH
```

## `CHUNK-ENS-D05-004`

```yaml
question: MarketCapture는 특허기술인가?
answer: KCE가 자체 개발한 운영 중 AI 입찰 플랫폼이라는 공식 근거는 있으나 초기 공개검색에서 KCE 명의 특허는 확인하지 못했다. 소프트웨어 저작권·영업비밀·데이터·모델 권리로 우선 분류한다.
confidence: MEDIUM_HIGH
```

## `CHUNK-ENS-D05-005`

```yaml
question: Honeywell ASCC는 E&S 보유기술인가?
answer: 공개자료상 Honeywell UOP 기술을 E&S 발전소에 적용·실증하는 협력이다. 핵심기술 소유권·라이선스·개량권은 계약 확인 전 E&S 보유로 분류하지 않는다.
confidence: HIGH
```

## `CHUNK-ENS-D05-006`

```yaml
question: Plug Power PEM 기술은 E&S 특허인가?
answer: SK E&S와 Plug Power의 JV를 통한 현지화·제조·실증 역량이다. Plug의 배경기술과 JV 성과의 권리경계는 계약을 확인해야 한다.
confidence: HIGH
```

## `CHUNK-ENS-D05-007`

```yaml
question: CO2 포집 직접 특허는 무엇인가?
answer: 2022년 12월 6일 우선일의 흡수제 고체화 방지 특허 두 건이 확인된다. 하나는 폐열을, 다른 하나는 포집 CO2를 활용하며 공개DB는 2025년 6월 등록·active로 표시한다.
confidence: HIGH_AGGREGATOR_REFRESH_REQUIRED
```

## `CHUNK-ENS-D05-008`

```yaml
question: 도시가스 특허가 D17에 주는 의미는?
answer: 장치특허 자체보다 정압·계량·열량·배관보수의 현장 문제와 발명자·자회사 네트워크를 보여준다. 신규 과제는 기존 장치에 데이터 품질·AI·로봇·작업증빙을 결합하는 방향이 적합하다.
confidence: HIGH
```

## `CHUNK-ENS-D05-009`

```yaml
question: 특허 법적 상태를 그대로 믿어도 되는가?
answer: 아니다. 공개 집계DB 상태는 초기 탐색용이며 상업 의사결정 시 30일 이내 공식 등록부로 갱신해야 한다. PCT ceased는 모든 국가단계 권리소멸을 의미하지 않는다.
confidence: HIGH
```

```yaml

confidence: MEDIUM_HIGH
```
