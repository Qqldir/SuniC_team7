| Program Domain | Code | 핵심 연구문제 | 대표 성과물 |
|---|---|---|---|
| LNG/Upstream | `RD-LNG` | 생산·액화·BOG·선박·터미널 최적화 | 모델·운전로직·센서 |
| Power/CHP | `RD-PWR` | 효율·예지보전·전기/열 급전 | 진단모델·디지털트윈 |
| City Gas | `RD-CG` | 계량·정압·누출·배관안전 | 장치·검사·RBMS |
| Renewable/PPA | `RD-REN` | 발전예측·O&M·정산 | 예측모델·정산엔진 |
| Liquid Hydrogen | `RD-H2` | 액화·BOG·물류·충전 | 공정·운영최적화 |
| Electrolysis/Fuel Cell | `RD-PEM` | PEM 설비·현지화·실증 | JV 제품·인증 |
| ESS/Trading | `RD-ESS` | 열화·안전·입찰·수익스태킹 | MarketCapture·WattBot |
