# 4. 기업 목적과 사업 정체성

## 4.1 공식 정체성

SK이노베이션 E&S 공식 기업소개는 LNG Value Chain 확장과 Power Value Chain Solution 통합을 기반으로 미래 에너지 문제의 지속 가능한 대안을 제시하는 `Sustainable Energy Solution Optimizer`로 성장하겠다는 방향을 제시한다. ([SRC-ENS-D01-0002])

```text
Historical Identity:
도시가스 지주회사 및 지역 에너지 공급자

Core Operating Identity:
가스전·액화·운송·터미널·발전·도시가스를 연결하는 LNG·전력 통합사업자

Expanded Identity:
LNG, 재생에너지, 수소, ESS, VPP, 전력망 운영을 결합한 에너지솔루션 사업자

Current Organizational Identity:
SK이노베이션 내부에서 독립경영되는 E&S CIC
```
