# 4. Public Financial Baseline

## 4.1 Scope Control

2026년 현재 외부 재무이용자는 E&S를 독립 상장사의 전체 재무제표로 보는 방식보다 SK이노베이션 통합 구조 안의 E&S 사업과 관련 자회사·SPV를 구분해야 한다. 2026년 2분기 E&S 사업은 매출 2조 5,961억원, 영업이익 1,059억원으로 공시됐지만 이는 `사업 실적`이며 E&S가 자유롭게 사용할 수 있는 현금·부채·CAPEX 한도를 뜻하지 않는다. `[SRC-ENS-D12-0003]`

따라서 D12에서 그룹 연결 자산·부채·현금, E&S 사업 손익, 프로젝트 SPV debt를 동일 분모로 나눈 부채비율이나 투자여력을 계산하지 않는다.
