## Chunk D03-002｜직접 PPA

```yaml
chunk_id: CHUNK-ENS-D03-002
topic: direct_ppa
answer: >
  직접 PPA는 재생에너지 발전사업자와 전기사용자를 공급사업자가 연결하는 장기 전력거래다.
  E&S는 PPA 비용분석과 상담을 제공하며 계약·정산·손해배상·부족/초과전력 처리 역할을 수행한다.
  O/I 핵심은 비용 시뮬레이션, 발전·부하 예측, 자동정산과 증빙 데이터 계보다.
source_ids: [SRC-ENS-D03-0003, SRC-ENS-D03-0005]
```

## Chunk D03-003｜액화수소

```yaml
chunk_id: CHUNK-ENS-D03-003
topic: liquid_hydrogen
answer: >
  인천 액화수소플랜트는 연 3만 톤 생산능력을 갖추고 부생수소를 액화해 2024년부터 전국에 공급한다.
  제품·서비스는 액화수소, 극저온 저장·운송, 충전소 공급 연계로 구분한다.
  핵심 O/I 영역은 액화 전력원단위, BOG, 탱크로리 배차, 충전소 재고·가동률이다.
source_ids: [SRC-ENS-D03-0004]
```

## Chunk D03-004｜ESS·VPP·DERMS

```yaml
chunk_id: CHUNK-ENS-D03-004
topic: ess_vpp_derms
answer: >
  ESS는 수요관리, 재생에너지 연계, 미국 계통안정화로 구분된다.
  DERMS와 재생에너지 O&M은 추진계획, VPP는 검토 단계이므로 상용제품으로 단정하지 않는다.
  우선 과제는 데이터 표준화, 자원 가시성, 예측·입찰·정산, ESS 열화·안전 통합제어다.
source_ids: [SRC-ENS-D03-0006]
```
