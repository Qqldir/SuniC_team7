> SK이노베이션 E&S · D04 기술 분류체계·핵심기술 마스터 · SK이노베이션 E&S AI Knowledge Database

## 0. 도메인 정의와 판정 규칙

D04는 SK이노베이션 E&S의 LNG, 발전·열, 도시가스, 재생에너지, 수소, ESS·분산자원, EV 충전, CCS에 필요한 기술을 동일한 체계로 분류한다. 특정 기술이 업계에 존재한다는 사실과 E&S가 실제 도입했다는 사실은 분리한다.

### 0.1 데이터가 답해야 하는 질문

1. 어느 제품·사업·공정에 연결되는 기술인가.
2. 필요한 센서·운영·시장·고객 데이터는 무엇인가.
3. 분석 결과가 어떤 설비·업무·거래 제어로 이어지는가.
4. E&S 내 공개 확인 상태와 외부기술 협력 가능성은 무엇인가.
5. 성과를 비용·생산성·품질·안전·자원효율 중 무엇으로 측정하는가.

### 0.2 기술 계층

| Layer | 정의 | 예시 |
|---|---|---|
| `L0_PHYSICAL_PROCESS` | 에너지 생산·변환·저장·운송의 물리공정 | 액화, 기화, 발전, 수소저장, CO2 압축 |
| `L1_ASSET_AND_SENSOR` | 설비·센서·보호장치 | 터빈, 펌프, 계량기, 누출센서, BMS |
| `L2_OT_CONTROL` | 현장 제어·운영기술 | DCS·SCADA, EMS, 충방전제어, 정압제어 |
| `L3_DATA_AND_AI` | 예측·진단·최적화 | 수요예측, 이상탐지, 디지털 트윈 |
| `L4_PLATFORM_AND_MARKET` | 자원·거래·고객 통합 플랫폼 | DERMS, VPP, PPA 정산, 고객서비스 |
| `L5_MRV_AND_ASSURANCE` | 측정·보고·검증·감사 | 배출 MRV, 데이터 계보, 안전검증 |

### 0.3 E&S 적용상태

| 상태 | 의미 | D17 사용 규칙 |
|---|---|---|
| `OPERATING_CONFIRMED` | E&S의 관련 자산·서비스 운영이 공개 확인됨 | 현장 개선·확산 과제 가능 |
| `CAPABILITY_CONFIRMED` | 기능 또는 적용방향은 확인되나 세부 배치가 미공개 | 내부 설치현황 확인 후 PoC |
| `PLANNED_OR_CONSIDERING` | 추진계획·검토 단계 | 소규모 검증과 경제성 확인 우선 |
| `ENABLING_CANDIDATE` | 사업에 필요한 외부 기술 후보이나 E&S 도입은 미확인 | 벤더 탐색용, 도입 사실로 표현 금지 |

### 0.4 핵심 제한

- 업계 표준 기술을 E&S의 보유기술·특허·내재화 기술로 단정하지 않는다.
- `AI`, `디지털 트윈`, `예지보전`은 목적이 아니라 입력데이터·제어대상·KPI가 있는 경우에만 Seed로 사용한다.
- 안전계통을 AI가 단독 제어하는 과제는 만들지 않는다. AI는 탐지·추천·검증 보조로 한정한다.
- 블루·그린수소, DERMS·VPP·재생 O&M, CCS는 D03 상태보다 높게 평가하지 않는다.
- 기술 공급사와 스타트업은 D16에서 연결하며 D04에는 기능요건만 저장한다.
