# 4. 데이터 준비도와 PoC Gate

| Gate | 확인사항 | 미충족 시 처리 |
|---|---|---|
| `GATE-D04-01` | 자산·태그·시간 기준이 연결되는가 | 데이터 정비 과제로 전환 |
| `GATE-D04-02` | 고장·사고·정비 라벨이 충분한가 | 비지도 탐지+전문가 검토로 제한 |
| `GATE-D04-03` | 추천 결과가 실제 조치·제어와 연결되는가 | 대시보드 과제의 우선도 하향 |
| `GATE-D04-04` | 기존 DCS·SCADA·BMS 안전로직을 침범하지 않는가 | advisory mode만 허용 |
| `GATE-D04-05` | 비용·안전·생산성 KPI의 기준선이 있는가 | PoC 전 baseline 측정 |
| `GATE-D04-06` | 계획사업의 내부 owner·예산·일정이 있는가 | 기술동향 모니터링으로 보류 |
| `GATE-D04-07` | 규제·개인정보·시장정산 제약을 확인했는가 | D14·법무 검토 전 외부확산 금지 |
| `GATE-D04-08` | 외부 솔루션의 OT 보안·데이터 반출 조건이 충족되는가 | 폐쇄망·합성데이터 실증으로 제한 |
