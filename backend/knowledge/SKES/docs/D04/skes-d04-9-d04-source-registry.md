## 사용 제한

- 본 문서는 공개자료 기반 기술·O/I 탐색 DB이며 E&S의 실제 설비설계, 제어로직, 특허소유, 벤더계약을 증명하지 않는다.
- 기술 후보를 도입할 때는 현장 안전성, OT 보안, 규제, 데이터 반출, 기존 OEM 보증과 장기정비계약을 확인해야 한다.
- D17은 20개 Seed를 그대로 과제 수로 계산하지 않고 D06~D16 근거와 중복·의존성을 병합한다.
- 내부 데이터가 없는 기술은 자동화 구축보다 데이터 진단·baseline·소규모 PoC를 우선한다.
