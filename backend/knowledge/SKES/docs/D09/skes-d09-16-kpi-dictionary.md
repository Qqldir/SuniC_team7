# 16. KPI Dictionary

## 16.1 Commercial and Contract KPIs

| KPI | Definition |
|---|---|
| Contracted Demand | 유효 계약 기준량; 실적과 분리 |
| Forecast Accuracy | 사업·고객·시간대별 WAPE/Bias |
| Forecast-to-Firm Conversion | forecast 중 firm order/award 전환율 |
| Contract Utilization | 실사용/계약 기준량 |
| Renewal Rate | 만료 계약 중 갱신 비율 |
| Pipeline Conversion | 단계별 전환율; MOU 별도 |
| Customer Concentration | top 1/5/10 매출·물량 비중 |
| Credit Exposure | 미수·향후 공급·담보 반영 위험액 |
| Obligation Compliance | 계약 KPI 충족 비율 |
| Revenue Leakage | 제공·계량 대비 미청구/오정산 |

## 16.2 Service KPIs

| KPI | Definition |
|---|---|
| First Contact Resolution | 최초 접점 해결률 |
| Average Handle Time | 상담 처리시간; 단독 최적화 금지 |
| Repeat Contact Rate | 동일 사유 재접촉 |
| Field First-Time Fix | 1회 방문 해결률 |
| Emergency Arrival | 신고~현장도착 |
| Bill Accuracy | 오류 없는 청구 비율 |
| Meter Read Quality | 실제·유효 검침 비율 |
| Digital Completion | 비대면 완료율 |
| Complaint Recurrence | 동일 원인 재발률 |
| Customer Effort Score | 고객이 과업 완료에 든 노력 |

## 16.3 PPA, BESS, Charging and Hydrogen KPIs

| KPI | Definition |
|---|---|
| PPA Load Coverage | eligible load 중 재생전력 충족률 |
| Hourly Shape Match | 시간단위 발전-부하 정합도 |
| Evidence Completeness | MWh별 인증 lineage 완결률 |
| Bid Acceptance | 제출 bid 중 award 비율 |
| Dispatch Performance | 명령 대비 실제 response |
| Settlement Recovery | 예외·누락 정정 회수액 |
| Charger Session Success | 정상 시작·종료 session 비율 |
| Fleet Departure SOC | 출차 목표 SOC 달성률 |
| Peak kW Avoided | 부하제어로 회피한 최대수요 |
| Station Throughput | 시간/일 kgH2 |
| Hydrogen Stockout | 재고부족 시간·건수 |
| Vehicle-to-Station Readiness | 차량도입과 충전소 가동 동시 충족률 |
