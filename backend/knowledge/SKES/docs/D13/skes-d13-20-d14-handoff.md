# 20. D14 Handoff

D13에서 D14로 넘기는 핵심 질문은 `계약상 해야 하는 일`이 실제 법·허가·시장규칙·보조금 조건과 일치하는가이다.

## Final Interpretation

SK이노베이션 E&S의 계약·거버넌스 구조는 제조기업의 단순 공급계약 원장보다 훨씬 다층적이다. Barossa의 joint operation, Darwin/Freeport/Boryeong의 서로 다른 equity·processing·tolling·terminal rights, 전남해상풍력의 JV/PF, KCE의 프로젝트별 SPV·vendor·전력시장 계약, EverCharge의 site/data 관계, 수소사업의 지분변동·기술권리·공공협력, Quynh Lap의 해외 consortium·정부승인·향후 PPA/EPC가 동시에 존재한다.

따라서 D17에서 좋은 O/I 과제는 `AI가 무엇을 할 수 있는가`보다 먼저 **누가 권리를 갖고, 누가 승인해야 하며, 어떤 계약상 의무·데이터·보증·Exit 조건 아래 실행 가능한가**를 통과해야 한다. D13의 핵심 산출물은 이 실행가능성 Gate다.
