# 10. Corporate, Subsidiary & Post-Merger Governance

## 10.1 Legal-scope ladder

```text
SK Group
→ SK Inc.
→ SK Innovation legal entity
→ E&S business / CIC
→ controlled subsidiary
→ JV / joint operation
→ project SPV
→ asset
→ agreement

```

분석·AI 검색에서 어느 단계의 사실인지 `scope_id`를 반드시 함께 저장한다.

## 10.2 2024 merger succession controls

2024-11-01 이전 SK E&S 계약을 현 SK Innovation E&S로 검색 가능하게 만드는 것과 법적 의무승계를 확정하는 것은 다르다.

| 확인영역 | 필수 증빙 |
|---|---|
| contract party | merger certificate·assignment/novation·counterparty notice |
| guarantee | guarantor succession/consent |
| permit | authority approval·name change filing |
| finance | lender consent·CoC waiver |
| IP/license | affiliate/successor clause |
| data | controller/processor notice·cross-border terms |
| insurance | named insured endorsement |
| litigation | party substitution/case status |

## 10.3 D01 gaps closed/handed forward

| Gap | D13 처리 |
|---|---|
| 최신 조직도 | public-only로는 완전확정 불가; internal request 유지 |
| 전체 자회사 법적명·지분율 | public subsidiary/filing + registry audit 필요 |
| 임원·자회사 대표 | current board/officer master 필요 |
| 합병 전후 계약 승계 | agreement-by-agreement succession ledger로 구조화 |
