# 9. Quynh Lap & Cross-border Development Governance

## 9.1 Consortium

2026년 Quynh Lap LNG-to-Power 사업은 SK Innovation, 베트남 국영 PV Power, NASU 컨소시엄이 사업자로 선정됐고 1.5GW 발전소·250,000m3 LNG terminal·전용항만, 약 $2.3bn 프로젝트로 공개됐다. 2026년 5월 infrastructure groundbreaking이 진행됐으며 상업운전 목표는 2030년이다. `[SRC-ENS-D13-0037~0038]`

| Governance issue | 공개 사실 | 내부 확인 |
|---|---|---|
| consortium | SK Innovation·PV Power·NASU | 지분·SPV·lead 역할 |
| government | Nghe An developer selection | IRC·concession·land·permit conditions |
| fuel | SK integrated LNG model | firm supply agreement·pricing·FX |
| power | 1.5GW target | PPA/offtaker·tariff·dispatch |
| terminal | 250,000m3 | ownership·TUA·third-party access |
| EPC | construction target | EPC allocation·LD·handover data |
| financing | ~$2.3bn headline | sponsor/PF split·guarantee |
| AI/DC | SEIC cooperation concept | binding load/offtake 여부 |

## 9.2 Development-stage Gate

```text
Developer selected
→ local company / SPV
→ land / concession / permits
→ PPA / grid / tariff
→ LNG supply / terminal rights
→ FEED / EPC / LTSA
→ financing / guarantees
→ construction / commissioning
→ COD / acceptance / operations
```

각 Gate가 완료되기 전 다음 Gate를 확정사실로 승격하지 않는다.

## 9.3 AI/Data clause opportunity

Quynh Lap은 아직 개발단계이므로 D17 관점에서 가장 중요한 기회는 완공 후 데이터 정리보다 **EPC 계약 체결 전에 asset hierarchy·tag dictionary·historian export·document metadata·digital twin handover·cyber/data residency 조항을 넣는 것**이다.
