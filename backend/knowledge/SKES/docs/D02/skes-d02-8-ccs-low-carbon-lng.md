# 8. CCS / Low-carbon LNG

## 8.1 사업 구조

```text
Barossa gas production
  → Darwin LNG liquefaction
  → CO2 capture and transport
  → Bayu-Undan depleted field storage
  → low-carbon LNG / future blue-hydrogen feedstock
```

공식 홈페이지는 Barossa–Darwin LNG–Bayu-Undan을 연결한 CCS 적용 계획을 제시한다. 그러나 포집률, 저장허가, 최종투자결정, 저장개시, 탄소강도는 별도 검증 전까지 계획·개발 상태로 둔다. ([SRC-ENS-D02-0002])

## 8.2 잠재 사업가치와 O/I 영역

| 가치 | 검증 필요사항 | O/I 탐색영역 |
|---|---|---|
| LNG 탄소강도 저감 | 전 과정 LCA·포집률 | MRV·LCA 데이터 플랫폼 |
| 블루수소 원료 | 생산단가·수요·규제 | 공정·물류 통합최적화 |
| 저장서비스 | 제3자 CO2 수용권리·허가 | 저장소 모델링·누출감시 |
| 규제·크레딧 대응 | 국가 간 인정체계 | 디지털 MRV·원산지 추적 |
