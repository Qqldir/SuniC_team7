> SK이노베이션 E&S · D02 사업 포트폴리오

# 2. LNG Value Chain

## 2.1 사업 정의

SK이노베이션 E&S는 가스전 개발부터 액화, 해상운송, 터미널, 발전까지 이어지는 LNG Value Chain을 보유·계약·운영한다. 각 단계의 소유권은 다르며 `지분 보유`, `사용계약`, `운영권`, `직접 운영`을 구분해야 한다. ([SRC-ENS-D02-0002])

## 2.4 고객과 수익모델

| 구분 | 데이터 |
|---|---|
| 내부·연계 고객 | E&S 발전소, 도시가스 자회사, 수소 프로젝트 |
| 외부 고객 | 국내외 가스·전력 수요자 및 거래상대방 |
| 공식 확인 수익축 | 천연가스·LNG를 확보해 발전과 도시가스 등 하류사업에 투입 |
| 추론 수익축 | 생산물 판매, 조달·판매 스프레드, 터미널·수송·계약 최적화 가치 |
| 핵심 경제변수 | 원료가, JKM·Henry Hub 등 가격지표, 환율, 수송비, 발전 SMP, 가동률 |

개별 계약가격, take-or-pay, destination clause, hedge 조건은 공개 사업소개만으로 확정할 수 없으므로 D08·D11·D13에서 다룬다.
