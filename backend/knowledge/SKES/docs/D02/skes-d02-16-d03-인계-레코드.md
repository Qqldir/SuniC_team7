## 사용 제한

- 본 문서는 공개자료 기반 O/I 탐색 DB이며 내부 사업계획·계약·예산·투자심의를 대체하지 않는다.
- 공식 계획과 실제 상업운전 실적을 혼합하지 않는다.
- 수익모델 중 공식자료가 직접 밝히지 않은 부분은 산업구조 기반 추론이며 D11·D13 검증 전 확정값이 아니다.
- D17 과제 생성 시 `P0` 영역을 우선 사용하고, `P1·P2`는 기술성뿐 아니라 사업단계와 내부수요를 확인한 뒤 추천한다.
