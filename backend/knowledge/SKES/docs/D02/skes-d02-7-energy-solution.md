# 7. Energy Solution

## 7.1 포트폴리오 구조

| Solution ID | 사업 | 고객가치 | 상태 |
|---|---|---|---|
| `SOL-ENS-001` | DERMS | 분산자원·배전망 통합운영 | Ensolve 기반 추진 |
| `SOL-ENS-002` | Demand-management ESS | 최대수요·전기요금 절감 | 제공 모델 |
| `SOL-ENS-003` | Renewable-linked ESS | 변동성 완화·예측정확도 개선 | 제공 모델 |
| `SOL-ENS-004` | VPP | 소규모 전력·REC 중개 | 검토·진입 단계 |
| `SOL-ENS-005` | Renewable O&M | 발전자산 운영·정비 | 추진 |
| `SOL-ENS-006` | EV Charging | 주차장 기반 충전 | iPARKING 연계 확장 |
| `SOL-ENS-007` | U.S. Grid ESS | 계통 안정화 ESS | KCE 운영·개발 |

SK이노베이션 E&S는 Ensolve의 배전망을 기반으로 DERMS·ESS·VPP·재생에너지 O&M을 추진한다. 미국 KCE는 뉴욕·텍사스 중심으로 약 0.6GW의 ESS 프로젝트를 개발·운영하는 것으로 공식 페이지에 설명돼 있다. 이 수치는 전부 상업운전 용량으로 해석하지 않는다. ([SRC-ENS-D02-0006])

## 7.2 수익모델

| 사업 | 수익경로 | 핵심 성과지표 |
|---|---|---|
| ESS | 설치·개발·운영, 수요관리 절감공유, 전력시장 수익 | 가용률, cycle, spread, 화재사고 |
| VPP | 전력·REC 중개, 집합자원 운영 | 참여자원, 예측오차, 정산수익 |
| DERMS | 플랫폼·운영서비스 | 제어자원, 피크절감, 장애시간 |
| Renewable O&M | 장기 운영·정비 수수료 | 가동률, MTBF, 정비비 |
| EV Charging | 충전요금·운영서비스 | 충전기 이용률, 고장률, 회전율 |

## 7.3 O/I 탐색영역

- 배터리 상태·열폭주 조기예측과 소방 연계
- 전력가격·기상·부하 기반 ESS 입찰·운전 AI
- 이기종 DER의 표준 연동과 실시간 제어
- VPP 자원모집·예측·정산 자동화
- 충전기 고장예측과 현장출동 최적화
- 주차수요·충전수요·배전용량 통합 최적화
