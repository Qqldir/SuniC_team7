# 4. City Gas

## 4.1 사업 정의와 규모

7개 도시가스 자회사가 전국 8개 권역에서 배관망을 통해 도시가스를 공급한다. 공식 홈페이지가 제시하는 2023년 말 기준 수치는 약 510만 가구, 54억㎥ 공급, 국내 점유율 22.6%다. 해당 숫자는 2023년 기준으로만 사용한다. ([SRC-ENS-D02-0003])

## 4.3 수익과 운영구조

| 요소 | 내용 |
|---|---|
| 제공물 | 취사·난방·상업·산업용 도시가스 |
| 고객 | 가정, 상업시설, 공공시설, 산업체 |
| 수익모델 | 지역 공급권과 규제요금 체계에 따른 가스판매 |
| 핵심자산 | 배관, 정압기, 밸브, 계량기, 관제·검침 시스템 |
| 계절성 | 동절기 난방수요가 높고 비수기 판매량이 감소 |
| 핵심 리스크 | 누출·굴착사고·노후배관·검침오류·수요변동 |

2026년 1분기 E&S 영업이익 증가는 동절기 도시가스 판매량 확대와 SMP 상승의 영향을 받았고, 2분기에는 도시가스 비수기와 발전소 계획정비로 이익이 감소했다. 이는 도시가스와 발전의 계절·정비 변수가 E&S 전체 실적에 직접 영향을 주는 것을 보여준다. ([SRC-ENS-D02-0007], [SRC-ENS-D02-0008])

## 4.4 O/I 탐색영역

- RBMS 기반 배관 위험도 고도화
- 드론·차량·고정센서를 결합한 누출탐지
- 굴착공사·지반변화·민원 데이터 기반 사고예측
- 기상·고객군별 일/시간 수요예측
- 스마트미터 원격검침 및 이상사용 탐지
- 정압기·밸브 예지보전과 순회점검 경로 최적화
